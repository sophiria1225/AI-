# P22追加点検：ファイル形式から計算ツール不足と決めない

2026年10月21日22時台、P24の途中本文を読まず、終了済みP22_03の公開観測だけを再確認した。`show_file`の18返却中、17件は文字列の内容を返していた。13件に通貨表記のある318〜319文字のテキストがあり、残る４件は`binary`という語を含む20文字の内容だった。PDFの先頭識別子がある返却は０。これは返却の出現回数で、異なるファイルの件数ではない。

したがって「PDF拡張子のファイルがあったので、PDFデコーダーを追加すれば解ける」とは判断しない。デコード可能なPDF本体を得たことも確認できない。どの期間・ファイルが本来必要かは別の問題であり、既知の時刻案内を補うP24を先に完了させる。これだけから計算能力不足や環境の解答不能を確定しない。
