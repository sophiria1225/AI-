# P78を原稿へ含める範囲

P78の全８条件を通常の失敗通知の比較として別表に含める。全使用量既知、両側3/4成功、例外通知側＋120,991 tokenで事前基準は未達だった。返金の実例外０、書出しの例外前の分岐、参照IDをそろえた事後点検も記述する。残時間１秒と出力差の同時観測を、１秒の因果効果と断定しない。

P55/P71の24表示条件、P56/P72の18終了診断、P66/P68の通常終了制御、P76の全８保持条件は、それぞれの元結果・欠測・採否を維持する。P78は開始状態・推論方針・予算等が異なり、過去比較の同時対照としてまとめない。既知課題を反復しても独立した確認課題が増えたとはしない。

題名は教授用に決めた「状態保持型LLMエージェントにおける情報保持と実行制御の評価」と対応する英題にそろえる。教授用456字あらましはそのまま保持し、原稿は投稿要領の和文120字・英文50語以内へ別途要約する。著者・所属は未設定で、公式クラスの確認と中心貢献は未完了。

生成器は閉じたP78の33ソース、７枚資料の目視記録、前の原稿生成器と全ての既存根拠を照合する。本文・文献４頁＋英文添付１頁を要求し、はみ出しや未解決引用があれば公開PDFの更新前に停止する。モデル・環境API・独立評価・再tokenizeを呼ばない。[反映前の原稿](../papers/202610_letter/archive_before_P78_20261023/README.md)を保存する。
