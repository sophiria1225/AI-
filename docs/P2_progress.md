# P2の検証記録

2026年10月20日。MiniMax M3の推論測定に先立ち、移管と計測基盤を確認している。

| 検証 | 結果 | 解釈 |
|---|---|---|
| 既存原記録の移管前後照合 | 1,279ファイル、不一致0 | 過去の実験結果を維持 |
| llama.cpp公式ARM64バイナリ | SHA-256一致、版表示成功 | 実行ファイルの起動確認。モデルのロード確認とは別 |
| 個別の公開検査記録 | 実コンテナの4確認に合格 | 先行失敗を後続成功で上書きしない |
| 費用処理 | 7テストに合格 | キャッシュの二重処理、欠落使用量のゼロ化、不完全応答の取り違えを防ぐ |
| 元コードの公開検査 | 15380は140件、15957は109件が合格 | 既存検査が動作する。要求された修正が不要という意味ではない |
| MiniMax M3の重み | 取得・ハッシュ照合中 | 品質結果はまだない |
| GitHub反映 | 未認証のためpush拒否 | ローカルコミットは作成済み。Issue・Projectは未作成 |

公開検査では最初にイメージのHEAD不一致で停止した。調査で課題元コミットとGit treeが一致することを確認し、内容の一致を検査するよう修正した。詳細は[判断D027](decision_log.md#d027-評価イメージの準備コミットとソース内容を区別する)。失敗した初回検査も`records/p2_public_baselines/`へ保持した。

モデル接続では、サーバーの`/v1/chat/completions/input_tokens`で整形後の入力を数え、生成後の実使用量との一致を検査する。推論テキストを履歴から勝手に削除せず、生成上限で途切れた応答のツール操作は実行しない。実モデルでの往復校正を終えるまでは、接続成功としない。

最終成果物は公開検査の前に凍結し、検査後の差分変化も確認する。独立評価は指定した凍結実行にのみ行い、既存結果を上書きしない。

原記録: `records/p2_controls/20261020_105107/`、`records/p2_public_baselines/20261020_105854/`。公開集計は[reports](../reports/)へ保存する。
