# 投稿原稿を２段組・４ページへ変更

2026年10月21日、ユーザーが「2段組４枚だった」と訂正したため、現在の原稿目標を**２段組・４ページ**に変更する。10月23日までの主要実験・あらまし、10月31日までの投稿完了という期限は維持する。以前の２ページ計画と、その時点の説明資料は履歴として保存する。この文書がページ数についての最新指定である。

推薦先は引き続き、和文論文誌D、人工知能・データマイニング、D140803「知識の共有・再利用」、レターの研究速報。ページ増加だけを理由に一般論文や別分野へ変更しない。

10月21日に再確認した[和文Dの投稿規定2.3](https://www.ieice.org/jpn/shiori/iss_2.html)では、レターの標準は２ページ、初回５ページ以上では超過理由書を求めている。４ページは標準ページ数を超えるものとして準備する。あらましは120字以内、英文アブストラクトは50語以内のまま。英文アブストラクト・英文キーワードは本文の標準ページ数に含めない。同ページの規定を用い、他誌のページ規則と混ぜない。

## ４ページに入れる内容

| 配置の目安 | 内容 | 満たす条件 |
|---|---|---|
| １ページ目 | 題目、あらまし、背景、問題、近接研究との差 | 一つの検証可能な主張。部品の列挙や新しい名称だけで独自性を説明しない |
| ２ページ目 | 問題設定、方式の状態・更新規則、構成図、単純対照 | 入力情報、予算、許される操作を明示する |
| ３ページ目 | 実験条件、主結果表、品質と総費用の図 | 未完了・不適合・不明費用も含める。基準実装の不備を提案の効果にしない |
| ４ページ目 | 要素比較、考察、限界、結論、文献 | 有効でない条件を残す。文献・図表・注記まで含めて収める |

これは段組みの割当案であり、実験結果や新規性が確定した原稿ではない。P16の主提案化は見送ったため、旧あらましの表示分離方式を確定題目として使わない。まず基準実装の不整合を除き、残る失敗と近接研究との差を確認する。

日本語PDFを作るローカルのTeX環境は確認済みだが、公式IEICEクラスの取得は未完了。したがって、４ページの公式組版に適合したとまだ報告しない。著者・所属情報も推測で補わない。
