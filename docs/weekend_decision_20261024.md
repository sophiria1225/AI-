# 10月24日：全仕事の通常対照と日曜の主張判断

必要な情報・処理と成果品質を保って、不要な取得・共有・モデル呼出し・実行・検証を減らすという最終目標を維持する。現在、新しい制御手法と一般的な品質維持は未成立である。P88の途中結果を見る前に、結果を原稿へ使う判断を整理した。25日に中心主張を絞り、29〜30日に原稿を整え、31日の投稿完了を目指す。採録を約束できる状態ではない。

## 実装済みの技術と研究上の位置

| 技術 | 具体的な処理 | 現在の証拠と位置付け |
|---|---|---|
| 状態と履歴の保持 | Python変数、API返却、返却済み推論を保持し、失敗時も作用と使用量を区別する | 通常対照の基盤。保持そのものを新手法とはしない |
| 通信参照の整形 | 呼出しと返答の対応を構造化された段階で統一し、その後に文章化する | P83/P84で１保存文脈の入力と次出力の関係を確認。P82の書出し両反復は整形後も未達で、品質回復は未実証 |
| 時間通知の時機 | 実期限は共通に強制し、表示だけを毎回・非表示・後半表示に変える | P82全24条件で後半表示の全４採用条件は未達。成功部分だけの減少で採用しない |
| 推論ブロックの通常上限 | 全出力最大4,096の中で、専用上限なし−1と固定2,048を比較する | P87は局所４件目で停止。P88は新しい初期状態から８条件を実行中。通常設定の全仕事への効果を調べる段階 |

現在の技術はハーネスエンジニアリングの範囲にある。「ハーネス」という語を外して目的を変えたわけではない。独自の判断規則がまだないことと、研究の対象領域は区別する。

## 近接研究と、今回だけで言える範囲

予算対応を学習する先行研究は、AppWorldで複数ターンを通じた予算内成功と自然な予算遵守を分けて評価し、未学習モデルにも同じ予算情報を与えている。１方策が扱う資源は１種類で、token費用は推論を含む生成分である。今回の学習なしの固定上限と全論理入力＋出力は比較対象・費用定義が異なるが、その違いだけで新規性にはならない。学習済みの方式に勝ったとも言えない。[Lambら v1、§4の設定・指標、§7、§11.8](https://arxiv.org/html/2610.28409v1)。

参照改名の先行研究では、有限の候補操作に制約した生成でも、業務IDの改名により選択が変わる反例が示されている。改名は探索で選ばれており、反例の存在を示す証拠であって発生率の測定ではない。今回の通信参照の退避表示とは対象が違うが、ID感度・入力正規化・構文上有効でも判断が正しいとは限らない点は既出である。[Mercado・Lomuscio v1、付録B.1–B.2](https://arxiv.org/html/2608.03609v1)。

通常の推論予算、残り長で完成可能な文法候補の選択、最短補完分の予約には先行例がある。[固定版の読取範囲](budget_completion_prior_scope_20261024.md)を保持する。一般構想が重なるだけで全研究余地を否定せず、今回の追加価値を判断規則、前提、費用、成果まで具体化する。

## P88終了後の分岐を先に固定する

| 終了後の状態 | 判断と次の作業 |
|---|---|
| 全８評価・使用量既知・監査一致、成功喪失０、両側成功１以上、全４課題費用減 | 固定2,048をこの開発群で有効だった通常設定として報告する。次の独自規則の比較では強い通常対照に含める。新規性や未見課題の品質保証へ格上げしない |
| 全件既知だが成功喪失・全費用増・両側成功０などで基準を満たさない | 改善として採用しない。どの課題の成否・費用が寄与したかを全件で示し、値やseedの探索で成功群へ置き換えない |
| 使用量不明・未評価・未実行が残る | 全８枠と欠測を保持し、全費用差が未確定の部分を明示する。既知部分や別実験で補充せず、停止理由を含め報告する |

いずれの場合もP87の未実行４枠や判定不能は変えない。P88の成否から事後にP87のコードを「正しい」と認定しない。生成内容・成否の比較は全条件終了後に初めて行う。

## 原稿に必要な決着

新手法として次へ進むには、通常対照後にも残る不要処理、実行時に使える公開根拠、判断規則、状態変化時の更新、追加費用、反証条件を一つの候補で示す必要がある。固定値の変更や既存部品の改名だけでは満たさない。保留12課題は候補を選ぶ用途に使わない。

現行の[実結果稿](../papers/202610_letter/closed_results_final/README.md)は、入力表現の局所差と全仕事の成否・費用を区別した限定的な実証である。４課題・１保存文脈・単一モデルという範囲では、採録に十分な中心知見だとまだ判断できない。実装数や整った資料でこの不足を埋めたことにはしない。

P88の終了後には、推論予算を中心に据えた別稿を作れるかを全件結果で判断する。本文４頁に過去の全診断を詰め込まず、問い・通常対照・全件結果・解釈を一つにつなげる。前の稿と全記録は保持する。教授用の日英題名と456字あらましは変更せず、著者・所属・順序は推測しない。教授への送信や実投稿は未実施である。
