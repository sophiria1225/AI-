# P98を加えた全件実証稿

閉じたP98の結果を[新しい原稿](../papers/202610_letter/execution_evidence_cohort/draft.pdf)へ加えた。本文４頁＋英文１頁、和文あらまし105字、英文47語、５キーワード、14文献。全５頁を確認し、組版警告、未定義参照、はみ出し、重なりは０だった。日英題名と教授向け456字あらましは変更していない。

前稿のP82全24条件、P84全18出力、P94の全実行に関する数値ファイルはbyte単位で保持した。説明の重複を整理し、新たにP98の全426生成、全60条件組、全1,132対応枠、重複を除いた生成・実行・課題数を掲載した。形式拒否と構文差・実要求一致の件数を分け、同じAPI列を正常完了・課題成功とは扱わない。

原稿の主張は、入力・出力の一致や構文の一致を報告するときに、提出・実行状態と実API要求を確認する必要があるという、この実装で得た具体的な証拠である。最も近い先行研究も行動の各段階を区別しており、測定項目を分ける一般形を新規手法にはしない。既知４課題の事後解析で、未知課題への一般性、新方式、品質を保った全仕事費用削減は未確立。

公開資料だけの検証処理も、この稿の174参照、既存の全数値表、P94全15組、費用・不明量の算術を確認した。P98の表は公開結果から全60組を再集計した内容へ照合した。これらは記載の整合性を確認するもので、非公開の元履歴を第三者が再評価した証明や、採録に足る新規性の判定ではない。

この全件実証稿を現在の投稿候補の作業版とする。P97は独立した固定比較として終了を待ち、途中結果を取り込んでいない。旧稿は全て保存した。著者・所属・順序、公式クラスとの同一性は未確認であり、投稿可能な最終版ではない。教授への送信・実投稿も行っていない。
