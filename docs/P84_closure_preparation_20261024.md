# P84の終了後集計と資料生成の準備

P84の実モデル診断は未開始。P82の全24条件比較を優先し、終了・所有推論器停止・最終実行判断の後にのみ進める。[固定計画](experiments/P84_fallback_output.md)の６入力・３反復・18生成と有限予算は変更していない。

`scripts/build_fallback_output_report.py` は、所有推論器が停止し、監査が完了した全18枠から５枚資料とCSVを作る。途中停止時も未実行枠を残す。使用量不明は空欄と不明件数で示し、０へ置き換えない。上限で途中切れになった応答も既知費用へ含めるが、完全出力の一致に基づく結論へは使わない。保存済み応答時間、既知生成のcache内訳、推論器の全稼働時間を区別し、重なる時間を加算しない。

条件内の全３対と条件間の全15組を、公開出力と全messageのhashの２種類で表示する。各条件間の最大９対は同じ生成を共有し、独立標本として扱わない。完全・非空の３反復と同値入力の対照が揃わなければ、ID差の局所効果は未確定とする。私的な推論の意味内容は読まない。

６つの検査で、全18枠・全15組の保持、使用量不明、17枠未実行、既知の途中切れ、不正な完了フラグ・不明件数、凍結入力の変更を確認した。全1,182検査は2.746秒で成功。完了・不明１件・１件だけ実行という３種類の合成記録を使い、各５頁をローカルだけで描画した。PDFの表の余白を修正し、欠測を含む頁も目視確認した。合成資料には表示検査であり実験結果ではない旨を記載し、実験結果や公開materialsへ混ぜていない。

既存17台帳の345出典hash、P82の46依存、P84の105依存は一致した。新しい資料作成処理はP84の入力・生成規則を変えない。実行に進む場合、最終HEADと両CIを確認し、凍結木から監査した後に次を実行する。

```bash
python scripts/build_fallback_output_report.py --pdf
```

生成先は `materials/20261024_p84_results`。実結果の全頁確認と出典台帳は別途必要であり、合成資料の確認で代替しない。現在の追加モデル生成・入力計数・環境API・独立評価は０。P84は一つの事後選定した保存文脈の局所診断であり、新手法、品質回復、全仕事費用削減の成立を測らない。
