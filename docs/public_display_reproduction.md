## 全件監査と限定した読取

`audit_public_display_comparison.py`は全12予定条件を扱い、保存した入力とAPI返却から各要求を再構成する。全入力出力・終端使用量・公開名と引数・スキーマ公開・復元・予算・評価ファイルの対応を確認する。追加の生成・API・再評価は行わない。不明使用量や未実行を既知の０へ置き換えない。

`inspect_public_display_outcomes.py`は、全４課題×３対について評価時の保存ファイルのハッシュだけを比較する。DBのレコード内容や非公開の個別テストを読む処理はない。`inspect_public_display_session.py`は、所有した推論器の終了記録とプロセス消滅を確認し、ロード・常駐・継続・復元等の重複する時間を分ける。評価単独の時間は未計測として扱う。

ローカルの完全な記録がある場合でも、これらの監査には終了した固定版とそのハッシュが必要になる。既存の監査出力は上書きしない。入力や実装が合わない場合に、検査を弱めたり実行を成功として付け替えたりしない。

## 公開結果からの再生成

P71の監査・計数・推論器集計が保存された後は、次の処理はモデル・模擬環境・評価器を呼ばない。

```bash
python3.12 scripts/build_public_display_paper_tables.py
python3.12 scripts/build_public_display_report.py --pdf
```

表の生成は標準ライブラリを使う。資料の図・HTML・PDFには既存の報告環境のmatplotlib、PlaywrightとChromium、日本語フォントを使う。Macのフォント配置は描画スクリプトに明記している。文書の見た目までOSをまたいで同一になるとは主張しない。

表と資料付属の `all_display_cells.csv` はP55とP71の全24予定条件を読み、異なる課題は４つとして記録する。成否、共通前半を含む総token、不明使用量、継続生成、継続と復元APIを元JSONから転記する。元P55をP71の値へ差し替えない。表・資料には参照JSONと生成スクリプトのハッシュを残す。PDFは出力後の全頁確認を別工程とし、生成しただけで確認済みにしない。

共通前半は、条件ごとの仕事全体費用として一度ずつ足す。同じ前半を実際に何度もモデル生成したという回数ではない。新たに実行した継続生成と、実験用に送信した復元APIは別の実測値として報告する。
