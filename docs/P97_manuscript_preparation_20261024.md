# P97の閉じた全結果を原稿へ移す準備

P97は実行中で、結果の先取りはしない。結果資料８頁とは別に、固定した全12枠をレター形式へ取り込む処理を準備する。既存の[実操作に焦点を絞った稿](../papers/202610_letter/execution_evidence_focus/README.md)は保持し、どちらを中心にするかは全件の監査後に判断する。題名は日英とも合意済みのものを用いる。

生成処理は所有サーバ終了、全12枠の監査、通知台帳、資源集計と878出典の照合を必要とする。監査不一致や未終了のまま原稿を作らない。未実行・未評価・不明使用量が残る終了記録は、その枠を残して取り込む。欠測のある全費用差は未確定とし、既知小計だけで改善とは書かない。

全12条件の成否・費用、N/G/Fの３対照、両成功・両未達・成否差・未評価の寄与、全条件の検出候補と通知の送信試行、所有サーバ全体の資源を掲載する。課題別の成功喪失と費用の欠測も別に表示する。G/Fの通知前入力が一致した送信試行の有無と、CSVの最終成否を明示する。

要旨と結論は、固定基準の達成・未達、使用量不明、未評価を区別して生成する。未実行が残る場合は全12回を実行済みとは書かない。達成時も通常対照の開発結果として記載し、新手法・一般的な品質維持とはしない。和文120字以内・英文50語以内を確認し、教授向け456字あらましは変更しない。

原稿ソースは[固定テンプレート](../papers/202610_letter/templates/recovery_notice_letter.tex)、生成処理は[スクリプト](../scripts/build_recovery_notice_draft.py)。全結果がそろった後に新しいフォルダーへ一度出力し、既存の組版処理で本文４頁以内と全頁の配置を確認する。現段階では実結果のPDFは生成していない。著者・所属・順序、公式クラスとの一致は未確認。
