# P71終了後の原稿への反映方針

2026年10月23日、P71の固定版実行中に記録。未終了の成否や費用を見て主張・条件を選ばないため、反映する比較範囲を先にそろえる。現在の４頁原稿はP68までの閉じた結果を保持している。

## 主要表

P55とP71の両方について、全４課題×全３表示の最終成否・共通前半を含む仕事token・使用量不明を載せる。既知４課題を２回扱うので、独立８課題または24独立課題とは数えない。基礎となる元の前半は同じである。課題や条件を除外して合計の向きを変えない。

P71内のD−F、D−Bを主要な対とし、初回入力短縮、継続費用、全仕事費用を区別する。仕事費用に加え、生成数、API、復元、制御、時間、推論器常駐を別記する。P55の不明１生成をP71の値で補完しない。未評価・未実行があれば、その状態を本文と表へ残す。

## 変えられる主張の範囲

| 終了後に確認するもの | 原稿での扱い |
|---|---|
| 両比較で初回短縮と総費用の向きが一致しない | 同じ既知群の２つの接続条件で観測した範囲に限定する |
| P71で費用の向きや成否が変わる | P55を消さず、適用範囲が接続・文面・実行条件に依存しうることを記す |
| Dが固定採用条件を満たす | この既知群での開発判断として報告する。一般品質保証や新手法に格上げしない |
| D/Bの一覧入力が同じ返金で行動が異なる | 時間通知と数値実装の変動を含む負の対照。差を一覧の効果に割り当てない |
| 公開名を説明前に呼んだ記録がある、またはない | 実際の送信数として示す。許可されているだけで正しい利用や品質は保証されない |

P55とP71は同時に実行した接続制約だけの対照ではない。共通の能力説明・ツール説明の修正と実行時点も変わるため、両者の差を呼出し制約の因果効果として報告しない。全条件１回ずつで、反復平均・信頼区間・非劣性は主張しない。

## 終了手続きの診断を維持する

終了後には全４課題のF/D・F/B・D/B、計12対について、評価時に保存したDBファイルのハッシュと完了通知数を同じ規則で照合する。DB内容や評価器の個別テストは読まず、追加実行・再評価・成否の付替えを行わない。一致は観測保存ファイルの範囲での一致、相違は直列化した保存値の差であり、それだけで作業品質の大小を決めない。

P56は旧写真の同一保存状態に完了通知を加えた別の診断であり、P71の通常生成へ合算しない。P71の成否が違っても、P56で確認済みの局所的事実は保持する。P66の写真の改善とP68の書出しの未達・削減なしも別条件として残し、P71の説明省略の成功数へ足さない。

４頁へ収める際は、数値・条件・限界を優先し、同じ説明の重複を削る。全24表示条件を付録への参照だけで隠さず、少なくとも成否と主費用を本文表へ載せる。最終目標は、必要情報と最終品質を保ちながら仕事全体費用を減らす制御であり、表示比較の追加だけで新規性不足が解消したとはしない。
