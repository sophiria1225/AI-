# 通常終了制御の結果を解釈するための近接研究の補足

2026年10月23日。P66の局所改善を確認し、P68の固定比較を実行している間の原典照合。P68の途中の意味的結果を見た方式変更ではない。新しいモデル生成・課題評価・保留群の閲覧はこの調査に割り当てていない。

## 読んだ範囲と重なり

| 原典 | 今回の読了範囲 | 本研究の判断への反映 |
|---|---|---|
| [AgentLoop, v1](https://arxiv.org/html/2609.33315v1) | 既存のIV–V節の照合に加え、VI節の対象・費用・検証器・ablation、VII節の限界 | 要求充足と停止を結ぶ制御、余分な反復や履歴の削減、判定費用の計上は既に扱われる。これらの一般論を新規性にしない |
| [EET, v2](https://arxiv.org/html/2601.05777v2) | 要旨、3.1–3.2節、4.2–4.5節 | 過去の成功経験と現在の編集・テスト等からLLMの信頼度を求め、生成・選択を止める。現在の公開API記録だけによる手書き検査とは入力と判断方式が違うが、費用を減らす終了制御そのものは既出 |
| [Prompt-Induced Waste, v6](https://arxiv.org/html/2608.01347v6) | 要旨、5–6.1節、11節。近接する3–4節の返却範囲も確認 | 余分な検証、案内・推論設定・ハーネスの相互作用、tokenと金銭・時間を分ける必要性は既出。「成功後」は可視テストの完了を代理指標としており、非公開評価の成功そのものではないという限界も明記される |

AgentLoopは検証器の時間も報告し、終了制御の内部指標と最終正確さを分離している。P66の0.028224秒を示すことだけで既存研究にない会計を提案したとはしない。原典の制御側ablationは複数の機構をまとめて外しており、個別機構の効果とは区別される。[原典VI–VII節](https://arxiv.org/html/2609.33315v1#S6)。

EETの停止には過去経験とモデルによる信頼度評価が入る。本研究の通常制御は現在の宣言済み契約を公開記録に照合するが、それ自体は[ECTとの既存照合](termination_control_overlap_20261023.md)に重なる。モデル判定を使わないという差だけで、未知課題での適用範囲や優位性は結論しない。[EETの方法](https://arxiv.org/html/2601.05777v2#S3)。

## 今回の結果に固有の根拠として残すもの

ここからは本リポジトリの結果と、上記文献を踏まえた研究判断である。先行方式の実装再現や同条件の性能比較ではない。

1. P55/P56では、写真の作業アプリの保存状態が一致しても公式成否が異なり、別環境で完了通知だけを加えると成否が切り替わった。単に「成功後に無駄がある」という観測よりも、作業状態と終了手続きを分けた局所介入として記載する。
2. P62では現在年の公開観測が足りず、元の公式成功を公開証拠による支持へ転記しなかった。P64/P65の別条件で公開根拠がそろい、P66で初めて実際に逐次制御した。この段階差と元の欠測・失敗を保持する。
3. P66は最終13保存ファイルと公式成功を保ち、両通常接続で全体tokenが減少した。ただし同じ既知１課題・各１回で、呼出しIDによる要求・応答全文の不一致も残す。
4. P67はCSV内容だけでなく、正しい書出しが退会より前であることまで要求した。P68でこの別の既知文型の実行費用を比較しているが、結果未確定の時点では削減を主張しない。

**暫定判断：通常終了制御を独自手法として売り出す根拠はまだ足りない。** 一方、上の局所介入・未支持の扱い・実測した費用差には実証資料としての価値がある。採録に足る追加知見かは別に判断する。要求文型の実装費用は実行時のtokenへ計上しておらず、あらゆる自然言語要求に無償で適用できるとも主張しない。

次の原稿更新では、終了制御の一般論にAgentLoop／ECT、経験による停止にEET、ハーネスと費用の依存関係にPrompt-Induced Wasteを対応させる。新しい表や一般化の主張はP68全件の終了・監査後に判断する。文献の要旨だけで再現済みや優劣確定とはしない。
