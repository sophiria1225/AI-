# 完全応答への取得余力を残す遅延読取の候補

2026年10月24日。P88の途中結果を使わず、以前のP69・P74で未解決だった将来参照の問題を、小さな実行モデルへ落とした。これは検討中の部品で、実エージェントへ接続した新手法や、課題品質・全費用の改善ではない。

## 対象にする問題

公開記録の[P69](P69_findings.md)には、曲詳細を要求する前にTitleとArtistsだけなら保持していた例があった。しかし部分情報を完全応答へ置き換えると、後で別項目を読むコードを壊す。[P74](P74_findings.md)の限定した静的破棄条件にも候補は０だった。この２つの元結果は変更しない。

候補は、完全応答を返せる義務を残して、既知項目の参照だけ先に満たすもの。現在読まれない項目を永久に削除する判定はしない。実行中に同じ対象への未取得項目が必要になれば、その時点で元の応答を取得する。状態変更の前には、旧状態の完全応答を確保する。

## 実装した規則

[実行可能な仕様](../scripts/deferred_read_obligations.py)は手書きのメモリ内世界と明示的な名前・別名・参照・破棄・変更だけを扱う。

1. 純粋で成功する読取、元時点に一致する部分値、全変更の捕捉という３前提が明示された場合だけ取得を遅らせる。不明なら即時取得する。この前提を自動で判定する機能はまだない。
2. 生きている部分応答１つにつき、完全取得１回分を予約する。実行済み要求数を `S`、残る予約を `D`、上限を `B` として `S + D <= B` を維持する。予約を実送信数や節約数へ計上しない。
3. 未知項目・応答全体の参照では予約を消費して完全取得する。既知項目の参照でも予約は残る。別名が一つでも残る間は取り消さない。
4. 最後の明示的な別名が消えたときだけ、その未取得要求と予約を取り消す。元情報が不要だったかを課題成否から推測しない。
5. 変更の直前に生きた部分応答をすべて完全取得し、変更後の参照でも元時点の値を返す。取得の契約違反は費用を残して停止し、自動再試行しない。

例えば題名だけを読んだ応答を別名で保持し、その後に対象を更新してから評価値を読む場合、更新前の完全応答を取得するので元の評価値が残る。最後の別名を更新前に破棄できた場合には、その完全取得を行わない。手書きの操作と単位費用における違いであり、実APIの削減測定ではない。

## 有限の検査結果

８境界検査に加え、８操作×長さ４の全4,096列を、即時取得と比較した。最後には残る全ての名前から完全応答を実際に読み出して比較し、将来参照を捨てて見かけの一致を作らない。不一致０、モデル化した要求上限の違反０。2,031列は同じ取得回数、2,065列は最後まで読まれず破棄された応答の分だけ少なかった。これらの列は独立した研究課題でも、現実の出現頻度でもない。部分情報の取得費用も測っておらず、削減率として外挿しない。

信頼した部分値が実は誤っている反例では、完全取得する前に誤った値を返せてしまうことも検査に残した。後から矛盾を検出できても、その前の誤りを防いだことにはならない。APIの意味・状態版を検証せずこの制御を使うことはできない。

## 先行方式と未解決部分

要求に応じた部分取得・再利用・変更時の無効化は既存の原理である。[LazyAgent v1](https://arxiv.org/html/2609.23058v1)の§3.1–3.2は型付きグラフと項目参照、増え得るグラフ・要求を扱い、§3.2・§9は作用の制約と資源の前提を分けている。未来の仕事が増えるだけで先行方式の対象外とはしない。今回の追加読取は§3.2、§9の該当記述、付録B.1であり、全実装や全評価の再現ではない。通常の需要追跡・予約・別名管理の組合せだけで新規性が成立したとも判断しない。

この仕様では、任意のPythonコードから別名・辞書への格納・未知関数・例外経路・状態変更を自動取得していない。実APIの純粋性や成功、認証、外部変更、経過時間も模擬世界の前提である。現在の`dict`を別の型へ透明に変えた場合の互換性を示していない。追加の前提を守るための問い合わせ・検証・全取得を、実仕事の費用へ含める必要がある。

次は明示的な読取ビューという同一インターフェースを即時方式と候補へ与えるか、限定したPythonだけを元の型・例外・別名の意味を保って変換できるかを判断する。P74の全２曲詳細箇所の追加の構文確認では、全応答が別の代入先にも保存されていた。根の参照を「全項目が必要」とも「すぐ破棄できる」とも扱えない。この２箇所を実API回数や改善見込みへ換算しない。

実行器へ接続でき、通常の完全保持・既存の項目読取との違いと全追加費用が固定できるまで、モデル実験には進めない。P88の成否・条件・推論器には触れていない。採録に足る新規性と有効性は引き続き未確立である。
