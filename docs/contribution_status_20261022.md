# 研究の目的と、現在まだ主張できないこと

2026年10月22日。主要実験とあらましを23日、投稿を31日とする目標は維持する。ただし、**投稿の中心となる新規性・性能維持と総費用削減は未確立**。実装が進んだことと、投稿可能な主張ができたことを分ける。

## 目的

AIへ渡す情報、取得、ツール実行、状態、検証、停止を制御するハーネスによって、不要な取得・共有・呼出し・実行を減らし、正しい最終成果を得る。当初の分担再編は、その目的を実現する候補の一つ。現在は単一作業役の入力と取得を測っており、複数担当の調整費用を削減したとは主張しない。

## 既存との差をどこで判定するか

部分キャッシュと意味的な問い合わせ再利用、状態付きツールキャッシュ、状態の可視化には先行研究がある。[確認した原典と範囲](data_reuse_overlap_20261022.md)。現在の「必要項目を明示し、既取得情報と照合する」という部品だけを、新規性として押し出すのは弱い。

P38では通常の同一要求キャッシュを超える利用はなかった。後続の読取対象は、保持していた12対象とは異なった。実装が動いても、この要求列での追加価値は示せておらず、拡大を見送る。[全結果と採否](P38_findings.md)。

論文の中心にするには、既存の仕組みだけでは解消しない具体的な失敗と、それに対する制御の追加価値、または十分な比較によって新しく明らかになる条件が必要。新しい名前や、部品を組み合わせたという事実だけでは補えない。

## レターへ向けた判定

P38全３件と独立再現監査は完了。①項目読取は使用されたが再利用なし、②全条件未達、③毎回取得に不明費用１件、④同一要求キャッシュを超える差なし、という結果だった。同じ初回入力・seedでも生成差があり、今後の比較では推論状態と実行順序も扱う。単純なキャッシュの拡大では、この不足を解消できない。

その判定ができるまで、あらましには改善率や「提案方式により品質を維持した」と書かない。既存の本文・あらましは過去候補の履歴であり、そのまま現研究の原稿にはしない。４ページ化、著者情報、正式書式の確認も残るが、それらを埋めるだけで研究上の不足が解消するわけではない。
