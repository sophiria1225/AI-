# ４ページ原稿で検討する主張と、その根拠

2026年10月23日、P61の通常対照確認後に改稿した。[原稿PDF](../papers/202610_letter/candidate_cost_completion.pdf)／[TeX](../papers/202610_letter/candidate_cost_completion.tex)／[数値・出典対応](../papers/202610_letter/cost_completion_source_map.json)。新しい生成や評価を加えた結果ではない。

## 原稿の問い

**共通の途中状態からAPI説明の表示を省いたとき、仕事全体の費用と最終成否がどう変わり、その成否差を実作業の改善と解釈できるか。**

現時点ではこの実証的な問いを検討原稿の中心に置く。必要な情報・処理と最終品質を保ちながら、制御・失敗・再取得を含む総費用を減らすという最終目標は維持する。この原稿を、新しい制御手法の有効性が成立した論文や、採録に足る貢献が確認できた論文とは扱わない。実証的レターとしての最終採用も未確定である。

## 最も近い研究との差

短縮と総費用の不一致は、[Beyond Token Savings](https://arxiv.org/html/2609.32961v1)や[Interaction Costs](https://arxiv.org/html/2608.16370v1)と重なる論点である。状態保持、段階的開示、API表現の分割も既存の設計であり、これらを組み合わせただけで独自手法とはしない。[これまでの照合範囲](inventory_retention_overlap_20261023.md)。

[Same Simulation, Different Evidence](https://arxiv.org/html/2610.26836v1)では、計算結果の生成・提示・最終回答を分け、計算を固定した継続比較も行われている。今回の対象は取得済みAPI説明の履歴と、操作先の状態を変えない完了通知で異なるが、段階別の診断や同一途中状態からの比較そのものを新規性にしない。[原典を読んだ範囲](evidence_delivery_overlap_20261023.md)。対象が異なることだけで十分な追加貢献があるとも判断しない。

読者への現時点の含意は、表示制御を評価するときに、入力の短さ・最終成否だけでなく、仕事全体費用と実作業・終了手続きへの作用を照合すること。ただし既知１課題の終了診断が、既存の注意点を超える再現性のある知見かは未確定である。

未閲覧12シナリオは方式選定に使わず、機構・比較・予算・欠測分析の固定後まで保持する。既存結果を有利にする再実行も行わない。10月23日の主要主張・あらまし、25日までの追加確認、29〜30日の原稿、31日の投稿という目標は継続する。
