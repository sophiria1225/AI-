# 回復制御の比較範囲と、P97終了後の判断

2026-10-24。P97の固定12条件を実行中に、閉じたP95/P96結果、既存の原典照合と追加の原典を整理した。P97の途中の意味的結果・出力を読んで方式を変更する作業ではない。追加のモデル・環境API・評価・未見課題を割り当てていない。

AgentRewindの主評価設定は、経過時間・総token・ステップの固定上限を置かず、同じ未充足項目を繰り返す終了条件を用いる。P97の有限な全仕事予算と外部評価をモデルに返さない設定とは異なる。これは評価条件の違いであり、P97が優れているという比較結果ではない。[原典の実験設定とB.4](https://arxiv.org/html/2608.14380v1)。

P94は新しい初期環境で保存プログラムの接頭部分を実際に実行し、28 API要求・返答等の一致を確認した。元のプロセス・DBの保存時点を復元した実験ではない。AgentRewindが明示する復元範囲を踏まえても、P94を一般的な同一実行状態の復元や安全な外部作用の巻戻しとは呼ばない。[P94全件](../materials/20261024_p94_results/README.md)。

## 現時点で分かっている差

P95の全399要求では、全引数が同じ再要求34件のうち、比較可能な30件の完全な返答が同じだったものは９件、異なったものは21件だった。対象読取の狭い範囲で、以前の成功した同じ要求が見つかったのは１件で、同じモデル境界内だった。要求の反復だけでは、モデル呼出しを除けるとは言えない。[P95全件](../materials/20261024_p95_results/README.md)。

P96では認証値の違いを分けると、対象読取の同じ返答は７件から34件に増えた。ただし、認証引数の単純除外とlogin要求の由来群の結果は34件で同じ、候補境界も同じだった。由来追跡を独自機構として採用する根拠はない。同じ値を再観測した事実は、要求充足・ローカル処理の進捗・現在の権限・将来の値の保証とは別である。[P96全件](../materials/20261024_p96_results/README.md)。

残る問いは、検出した候補に介入すると最終成果までの挙動が変わるか、その改善が一般的な見直し通知を超えるか、制御と失敗を含む全仕事費用が減るかである。これはP97で固定済みの比較に対応する。通知なし・一般通知・事実通知を比較する結果は、既存回復方式への優越を直接示すものではない。[P97固定手順](experiments/P97_recovery_notice_comparison.md)。

## 終了後に決めること

1. 全12条件の独立評価、使用量不明、未実行、通知の送信試行をそろえる。成功した条件だけを選ばない。
2. CSVの完了と、全課題での成功維持・全費用差を別に確認する。未達を安く終えた差を完了品質の改善にしない。
3. 事実通知と一般通知の前史が一致した実送信があるか確認する。基準未達なら、同じ結果を見て閾値や通知文を調整した再試行を自動追加しない。
4. 成立した場合も、通常対照が有効だったという結果として残す。その対照を超える具体的な機構、適用条件、実際の便益を別に示せて初めて主提案候補とする。
5. 未見12課題は保留する。既知課題の失敗を見ながら新規性を探すために開かない。

新規性を主張できないことと、得た実証結果に価値がないことは同じではない。ただし、記録・監査の実装量や検査数だけで研究の中核は成立しない。現在は、一般制御の局所的な改善と全仕事での未達、表示と実行の差、認証値による再観測判定の差という限られた知見がある。これを新手法や採録の見込みへ拡張する根拠は、まだ足りない。
