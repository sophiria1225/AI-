# 専用Projectの全ページ照合

研究Projectが100項目に達したため、`scripts/sync_tracking.py` の所属確認をページ送りへ対応した。変更先は引き続き `sophiria1225/AI-` とその専用Projectだけである。

`repositories` と `items` を独立に末尾まで読む。他リポジトリ、所属不明の内容、draft、GraphQLの部分エラー、ページ情報の欠落、cursor欠落・反復、空の継続ページを拒否する。全ページの確認が完了する前にはProjectのlink・item追加・編集を行わない。既存のIssue同期の復旧処理と全件ボード生成は維持する。

追加７検査を含む全958検査が1.626秒で合格した。101番目の項目や関連リポジトリの後続ページに別リポジトリが現れた場合も、変更前に停止することを合成応答で確認した。

実Projectでは変更前のrepositories１・items100を確認。R101を追加した直後の読取では100件が返り、期待する101件と違ったため、追加書込みをせず照合した。その後のGraphQL `totalCount` は101、CLI一覧も101でR101が含まれ、全ページの所属確認も101件となった。全て許可リポジトリに属していた。直後の100件という読取結果を、101件を確認済みだったことへ変更しない。

ページをまたぐ読取がGitHubの同一時点の完全なsnapshotになるという保証は追加していない。今回の変更は同期の継続に必要な保守であり、研究の新方式やモデル実験としては数えない。[R101](https://github.com/sophiria1225/AI-/issues/292)。
