# 欠測と入出力列の一致を分ける補助集計

2026-10-24。P81の固定反復を継続中。元の全件照合は、両実行の全使用量が既知の場合に完全一致を判定する。その報告は変更せず、保存された要求、公開出力、返却メッセージのhashについて、どこまで観測できたかを別に集計する[補助部品](../scripts/summarize_budget_visibility_prefixes.py)を追加した。

最後の使用量・応答が不明でも、その呼出しの要求JSONが残ることはある。要求が全部一致すること、観測済み出力が途中まで一致すること、最後まで出力が一致することを区別する。未実行同士や欠測同士を一致とはしない。呼出し数が違えば、共通部分が一致しても全列の一致とはしない。

全24対を保ち、最初に観測した差、最初から連続して一致した呼出し数、欠けているhash数、片方だけにある呼出し数を出す。最初の要求差より前に返却が違った場合や、先行入力が不明の場合も区別する。時刻値を参照する場合は、固定照合が保存した通知ファイルのhashを再確認する。返却された内部推論はhashだけを使い、意味内容は読まない。

追加６検査と全1,126検査を通過した。生成・API・評価は０。補助集計の実データへの実行は、P81全件終了と所有推論器停止後に行う。現在、結果ファイルは未作成である。保存JSONの一致をモデル入力token列やGPU状態の一致に置き換えず、最初の時計差を費用差の因果効果ともしない。

[全件の終了後手順](P81_closure_reporting_20261024.md)に沿って元の監査・全24対の照合・推論器時間を作った後、補助集計を行う。元の使用量不明、成否、採否基準は保持する。
