# 最新版とは区別したレター組版の予行

2026年10月23日。公式ZIPの同一URLへの再取得は行わず、既に検査済みの[公開ミラー固定版](https://github.com/mar-tusita/ieicej-platex/tree/09affdda87853ac52313ec92ae90e0f14a43a20d)で現原稿を予行した。前回は最新版との不一致を理由に実行していなかったが、今回は最新版の代用ではなく、投稿用マクロへの移行で生じる組版上の問題を調べる範囲に限定した。

`readme.1st`の日付は2026年１月５日だが、クラスの宣言は `2023/11/21 v3.4a`。ミラーの説明にあるv3.4bや、公式ZIPの更新日との同一性は確立していない。原４ファイルのSHA-256を再照合し、クラスは無視対象の出力先へだけ複製した。Gitへのクラス転載・外部スクリプト実行・公式配布先の再試行は０。

`letter`、`newtxtext`、`newtxmath`をテンプレートの指定に沿って使用し、著者情報は推測せず未設定と表示した。本文・表・文献・要旨の入力は現在の検討原稿からそのままコピーし、内容・成否・費用は変更していない。英文要旨・キーワードはクラスの末尾出力を用いた。主PDFは保持し、先頭に「組版予行・未投稿」と記した別PDFを生成した。

本文４頁＋英文末尾１頁となり、全５頁を目視した。はみ出し、overfull/underfull、未解決引用／参照は０。これは当該ミラー版・未設定著者欄でのページ数であり、最新版や実著者情報を入れた最終確認ではない。

初回はxpatch、第２回はscalefnt、第３回はtxttの不足で停止した。専用TinyTeXへ必要な依存関係を追加し、第４回に描画した。scalefnt/centernotは独立パッケージ名ではなくcarlisle/oberdiek内のファイルと配布側の検索で確認した。インストーラはGPG不在を報告しており、パッケージ署名を検証したとは扱わない。読み込まれた74個のTeX配布入力と実行器のSHA-256、失敗ログのハッシュを[記録](../reports/ieice_mirror_preview_20261023.json)へ残した。shell escapeを無効にし、ファイル入出力制約を設定して局所出力先で実行した。
