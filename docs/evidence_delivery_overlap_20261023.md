# 計算結果・観測・最終回答を分ける診断との近接性

P61の固定比較を実行中に、[Zhangほか、Same Simulation, Different Evidence v1](https://arxiv.org/html/2610.26836v1)を確認した。2026年10月19日の公開原稿で、今回読んだのは要旨・導入・付録Dの境界選定と対になった継続の部分。本文全体、実装、正式採録は未確認。

この研究は、決定的な科学計算の結果が作られたこと、モデルがその値を見たこと、最終的に正しく答えたことを分ける。計算を固定して返却方式を変え、同じ履歴・ファイル・残り予算から複数回継続する設計も示されている。原典の性能値を本研究へ移したり、仕組みが同一だと断定したりはしない。

P55/P56の「作業状態が同じでも終了操作で成否が変わる」という事例は、科学計算の値の丸めや参照元選択とは異なる。ただし実行・露出・最終回答を分ける一般的な診断観点や、同一途中状態からの比較そのものを本研究独自の貢献にはできない。AppWorldの１事例を増やしただけで十分とせず、既存の分解では判断できない制御条件または再現性のある追加知見が何かを特定する必要がある。

この原典はP61の条件固定後に確認した。実行中の２条件・予算・停止規則は変更しない。P61は通常の実行能力を点検する局所比較として位置づけ、一般的な品質維持や新方式の成立とは分ける。
