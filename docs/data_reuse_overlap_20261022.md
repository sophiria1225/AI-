次の候補は、生成された処理が要求する対象・項目と、既取得の観測の対応を使う再利用である。ただし、部分キャッシュ、問い合わせ書換え、遅延取得、動的スライスはそれぞれ既存分野との照合が必要。実装名を変えるだけで差を作らない。

現時点でP35は通常の参照計測と対応確認であり、論文の中心となる新規技術ではない。次の方式に必要な具体的差分は、①実行前に利用できる情報だけで選べること、②要求と記録の対象・版・項目を照合できること、③不確かな場合の取得を残すこと、④余分な照合費用を含めて総費用を減らせること。これらを実現・比較した結果が出るまでは、差分候補にとどめる。
