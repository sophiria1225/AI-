# P106: 通常呼出しの完全応答キャッシュで１API差は消えた

同じ通常キャッシュを両方式へ与えると、P105の手書き７段階の合計は即時版12 API、参照共有版12 APIとなった. 全14段階が正常終了し、７段階すべての標準出力hashが両側とP105に一致した. 取得時点は異なるが、この列全体で参照共有版固有のAPI削減は確認できなかった.

| 段階 | 即時＋通常キャッシュ | 参照共有＋通常キャッシュ |
|---|---:|---:|
| 1 初期の公開情報取得 | 6 | 6 |
| 2 重複参照と既知項目 | 1 | 0 |
| 3 未知項目と完全値 | 0 | 1 |
| 4 参照の一部解放 | 1 | 0 |
| 5 最後の参照解放 | 0 | 0 |
| 6 通常呼出しと参照 | 1 | 1 |
| 7 状態変更前後 | 3 | 4 |
| **合計** | **12** | **12** |

P105の即時版13回は、段階６で通常の`call_api(show_song)`が取得済みの完全応答を使わないことによる. 今回は同一実行範囲・状態版・全引数・検証済み公開契約の完全応答だけを両側で利用し、即時版に通常キャッシュhitが１件生じた. 部分値を完全値の代わりにはしていない. 参照共有版の重複参照共有４件、通常取得後の参照解決１件は動作したが、最後のAPI数は同じだった.
