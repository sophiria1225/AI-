# P127: finite whole-task region projection preparation

This is preparation source, not a launched experiment or an outcome claim.
No plan, initial count, activation, model request, task API, evaluator call, or
saved generated program is run by preparing these files. A future invocation
requires the closed P125 cohort, finite closed P126 offline evidence, a frozen
plan, exact-source CI, a finite owned server lease, and explicit parent launch.

The fixed comparison contains all four already exposed development tasks and
two policies: `explicit_joined_fields` and `automatic_region_joined_fields`.
Both provide exactly the same `read_fields` capability and guide, trusted joined
authority, ordinary complete-response cache, public-schema error feedback,
lossless compact receipt table, hidden wall-time notification, model seed 157,
world seed 42 and `rolling_separate` checkpoint. The optional automatic policy
also transforms admitted regions in ordinary `call_api` programs. Joined fields,
explicit demand and the adapter are ordinary shared components, not novelty.

Each cell has at most 80 shared agent/focus calls, 450000 logical tokens and 1800
work seconds. Separate summaries have at most 3 opportunities, retain the same
P123 thresholds and require 3 fresh turns. Their tokens, counts, native input
counts, control time, failed summaries and recovery remain inside the shared
ledger. At most 24 summary calls fit inside the batch's 640 total model calls.
The eight cells reserve 3600000 logical tokens and 8 evaluations, with no retries,
replacement cells, seed search, adaptive extension or hidden extra scenario.
The owned server lease is 21600 seconds. Setup 120, cleanup 180, idle recovery 60
and evaluation 180 seconds remain separately bounded per cell.

API limits are fixed by task slot: Photo 160, Expenses 80, Refund 80 and CSV 120 in
each policy, totaling 880 actual requests. CSV 120 is a new common finite limit
to test beyond the closed P125 80-request failure frontier; it does not revise or
pool any P125 result. Initial model inputs and public budget notices match
within each task pair. Full cache hits and partial field reuse make no API
receipt rows; actual dispatched requests, failures and unknown effects retain
the original typed receipt and shared reservation accounting.

P126 is a source-bound finite prefix diagnostic. Its required report accounts
for all original sources, observes region partial hits, executes no unobserved
suffix, preserves original sources, records zero additional model/API/evaluator
calls and no replay audit errors, and separately passes synthetic normal-path
contract tests. A saved frontier need not reach a normal final root boundary.
It establishes neither task completion nor measured token savings. P127 must
retain the exact source bytes validated by that report; no model sees a replay
result or independent evaluation.

The worker preserves raw records and generated source. The auditor only
reconstructs saved control, source hashes and evidence; it does not execute
generated programs or inspect evaluation content. All eight planned slots
remain visible as evaluated, unevaluated, not run, incomplete worker or audit
error. Dispatched unknown model usage remains unknown. Known contract stops
retain official outcome and paid cost, but prohibit adoption. Unknown API
effects or failed cleanup stop the batch. The server and reporting path are
exclusive, preserve failed attempts and never overwrite previous output.

The development gate requires all eight evaluated with known usage, no baseline
success lost, lower whole-cohort logical tokens, lower logical tokens on tasks
successful in both policies, at least one automatic partial hit on a common
success, and no projection contract failure or missing mechanism flag. Cheaper
failed cells, API counts, metadata bytes, or a shared explicit field hit alone
cannot satisfy this gate. Common-success cost is reported alongside all-eight
cost rather than replacing it. No general quality preservation, noninferiority,
heldout generalization or technical novelty is established by this screen.
