# P16の意味監査と使用量監査

2026年10月21日。P16の生成を継続しながら、全出力を評価する手順を固定した。１出力の完了と使用量は確認済みだが、生成された台帳の内容はこの手順の保存前に閲覧していない。生成前の事前登録とは呼ばない。[固定した判定規則](../../configs/P16_semantic_review_v01.json)。

全ての構造適合出力の全項目を対象にし、元入力だけ、拒否出典だけ、誤りらしい例だけを選ばない。doneは「操作を実行した」だけでなく「対象を調査した」「仕様を確認した」にも使えるため、出典IDやstatusの機械検査だけで誤完了を確定しない。

主に数えるのは、操作や作用を完了したと記録しているが、その位置までの実行証拠で支持できない項目。拒否された要求でも、以前に同じ操作が既に完了していれば支持され得る。人工条件には新たに動かした環境がないため、証拠のない完了と実世界の状態が偽であることを区別する。

表示条件・呼出番号を伏せたローカルの確認用入力を作り、固定した順序で判定してから対応表を開く。拒否状態は証拠から分かるため完全な盲検ではない。助手１者による探索的監査であり、独立した人間による確認や一致率を実施済みとはしない。曖昧例、形式不備、使用量不明は除外せず別記する。

使用量監査器は、固定ソース、元入力ハッシュ、比較順序、実際のseed・入力、入力計数、モデルの返却使用量、保存した台帳を再計算する。記録通りの３表示は入力が等しいことを確認し、出力差があれば表示介入の効果としない。終了前の監査を最終結果として保存することを拒否する。

正しい記録、seed・使用量の改変、実行中の記録を使う検査を含め280検査が合格した。これは監査処理の確認であり、台帳の意味や新規方式の有効性の検証結果ではない。実行ソースは引き続きP16 v02のまま固定し、後処理コードを実行中の入力へ戻さない。
