# 初回の実行可能性検証

目的は、既存モデルで応答・ツール呼び出し・全費用の取得が可能かを確認し、実問題のE0へ進む条件をそろえること。

対象モデル：既存の`qwen3.8-flash-next:125b-mlx`。Ollama APIの型、ダイジェスト、設定を保存する。初回はthinkingを無効にした短い形式検証であり、この設定の研究上の優劣は評価しない。

モデル接続検証は最大3呼び出し、各最大256出力トークン、要求コンテキスト上限8192、各120秒上限。合計入力と出力の計数上限は12000トークン。実際の有効コンテキスト上限はAPIの状態も確認する。計数欠落時は欠落として記録し、推定ゼロにしない。

1. 短いJSON出力と計数値を確認する。
2. 固定した読取専用ツールを一度呼ぶ。
3. 返却したツール値を最終回答へ使えるか確認する。

ツール試験は合成の接続試験であり、大規模情報処理能力やハーネス改善を示す結果ではない。モデル生成コードは実行しない。

保存対象：要求JSON、応答の全イベント、開始終了時刻、終了理由、入力・出力・キャッシュ計数、モデルロードと生成の時間、期待した形式との一致。原レスポンスと集計値を別々に保持する。

停止：最初の呼び出しに失敗、計数欠落、予算上限、想定外ツール、応答形式不適合があれば後続呼び出しを停止して原因を調べる。
