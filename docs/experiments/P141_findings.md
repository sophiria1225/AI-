# P141：差分表現を固定した要約時機の3条件診断

P141は既知のCSV課題（元のTask4、診断内slot1）を、TR→TDO→EDOの固定順で各1回実行した開発診断である。全3条件の公式評価が完了した。TRとTDOは成功し、EDOは作業時間制限に達して失敗した。TDOはTRより2,807 logical I/O tokens（TR比約0.844%）少なかった。一方、EDOは最後の1呼出しの実使用量が不明で、確定総費用の比較はできない。**これは単一既知課題での記述的な観測であり、採用・一般的な品質維持・未見課題での確認を示す結果ではない。**

実行sourceは `5cab33a2e239f3e6d90e63e32c54ba0764b1c594`、固定plan SHA-256は `5dd2581f4aae9fc8831768018a9fe00835c74e8b4f8506d0b77bda5f155ac18d`。元pipeline・audit・session・reportはすべてexit 0で閉鎖し、固定独立metadata checkerもPASSとなった。これらの運用上の成功と、各課題の成功・科学的採用を区別する。集計と図の作成でモデル・環境API・native計数・評価器を追加実行していない。

## 全3条件

全actor/focusのlogical input＋outputを計上し、cached inputを控除しない。使用量が既知の失敗呼出しも除外しない。

|---|---|---|---:|---:|---:|---:|---:|---:|---:|
|TR|入力長閾値・再帰要約|成功|319,446|13,142|332,588|0|31|76|1,498.7|
|TDO|入力長閾値・旧要約＋差分object|成功|316,696|13,085|329,781|0|30|78|1,501.6|
|EDO|E≥C・旧要約＋差分object|失敗：`wall_limit_during_model_call`|301,874|16,046|317,920|1|31|78|1,799.4|

3条件合計は92モデル要求、232環境API要求、3評価。既知費用の小計980,289と不明1呼出しを保持する。欠けたusage件数欄は0条件であり、EDOの「不明1件」と区別する。TRとTDOの行別費用は確定しているが、固定された全条件集計 `total_tokens_by_mode` は「3条件すべての会計が既知」という条件を満たさないため全方式nullのままである。行別の確定費用や既知pair差で、この集計欄を上書きしない。

## 3つの比較を分ける

差の向きはcandidate−baselineである。

|比較|baseline→candidate|成功の組合せ|確定token差|共通成功上の差|位置づけ|
|---|---|---|---:|---:|---|
|時機|TDO→EDO|成功→失敗|null|null（共通成功なし）|同じ差分表現・object指示で発動規則を比較|
|強い通常対照|TR→EDO|成功→失敗|null|null（共通成功なし）|方式全体の比較|
|表現＋prompt bundle|TR→TDO|成功→成功|−2,807|−2,807|閾値を保ち、保持表現と差分object指示を合わせて変更|

TR/TDOの約0.844%はこの1pairの記述値であり、object指示だけの効果ではない。EDOの既知小計が小さくても、未知費用を補完して削減率を算出しない。全3比較の `comparison_gate_met=false`、`scientific_adoption_evaluated=false`、全体の `development_gate_met=false` を維持する。P141では設計上採用判定を実施しないため、falseを新たな合格条件へ緩和せず、運用監査の失敗とも呼ばない。

## 最初の時機分岐と実際の介入

TDO/EDOの最初の観測発動判定差は、全モデル要求19件の後、次の `call_020` の前だった。同境界の保存scalarは E=22,306、C=21,419、現入力14,027。EDOはE≥Cを満たしてfocusを送り、TDOは14,027<16,384のためactorを送った。両送信ともterminal usageが既知である。

その境界までのprefixは、元監査の厳密比較では不一致、検証済みtransport tool IDの全単射だけを正規化した比較では一致だった。状態・request・既存要約・E/C等を勝手に同一視しない。ここでの独立確認は公開されたdigestとscalarの照合であり、本文を再読してcanonicalizationを再認証したものではない。第二focusのcutoffが同じことは要求せず、最初のpredicate差が未送信だった場合に後の有利な境界を選び直すこともしない。

TR/TDOでは第二focus前の22要求後までの比較が、同じくstrict不一致・canonical一致と記録されている。両方式の第二機会は採用された。採用時の全actor入力の局所比較はTRが16,474→6,002、TDOが16,474→6,179。EDOは19要求後に第二focusを送り、採用時に14,027→6,058となった。これらは固定producerが保存・束縛したnative計数であり、再計数ではない。TDO/EDOの旧要約＋差分は実際に後続actorへ届いたが、局所短縮・実配信だけで最終品質や全ジョブ節約を保証しない。

## 言えることと言えないこと

この固定診断では、閾値のまま差分表現とobject指示を使うTDOが成功し、TRよりわずかに少ない確定logical I/Oを記録した。E/Cで第二機会を前倒ししたEDOは差分を採用・配信した後に時間切れで失敗した。したがって、差分の配信可能性と時機変更の結果を区別する観測になっている。ただし、要約内容・後続行動・環境状態・失敗原因の意味的診断は行っておらず、「早い要約だけが失敗原因」とは断定しない。

課題はP140の結果を見た後に選んだ既知Task4、model seedは57のみ、順序は固定で無作為化していない。役割ごとのseed増分が同じ規則でも、時機が変われば後続payloadと軌跡が変わる。host・cache・wallの影響が残り、統計的非劣性、独立再現、一般的優越性を示さない。P140/P123の値を合算・置換せず、過去とのscalar一致も新しい独立標本とは数えない。元の既知4課題比較と予約された未見12課題の確認を置き換えず、未見課題の内容を開いていない。

E/Cは過去の再提示を用いる経験則であり、将来の償却保証ではない。差分計数・段階的要約・有料圧縮を含む費用評価自体は先行研究にある。[主張範囲の補足](P141_claim_scope_20261028.md)はsource固定後に追加調査した時点も明記しており、先行調査の事前登録や新規性の保証として扱わない。
