# P14：通常の作業台帳を同じ接続で比較する

P12の第3課題では既知の情報を繰り返し取得した。直近の原文だけを残す方式に対し、観測した対象、必要な操作、進捗、条件、認証等の継続情報を台帳に残す通常の対策で十分かを調べる。旧P6の台帳とは接続と対象が異なるため、旧スコアを比較値として流用しない。

これは新手法ではない。P6で使用した台帳プロンプト、項目、出典IDの形式検査を再利用する。人が正しい台帳を渡す方式や、認証だけを事前に永続化して正解を補う方式とは区別する。

## 固定する手順

1. 原会話は全て保存し、前回残した応答に新しい実行結果を加える。以前の台帳があれば同じ入力に添える。
2. 元のtaskとsystemを除く会話JSONをモデルのトークナイザーで数える。台帳・アーカイブ一覧・注意文もこの履歴代理計数に含める。
3. 4,096を超えたら、元task、現在見えている原記録、前回の台帳、実行役に公開済みのAPI仕様から台帳を1回生成する。渡すAPI仕様はデータであり、呼べる機能はsubmit_ledgerだけ。
4. 台帳はitems、constraints、unresolvedを持つ。itemsは観測した対象と要件、pending/done/uncertain/excluded、source_idsを保存する。以前のitemsが引用していた出典は引き継げるが、自動で再読したことにはしない。
5. 形式が適合したら直近2spanと新しい台帳を残す。操作と結果の組を切らないため、該当する元応答全体へ保持範囲を広げる。
6. 不正な形式や未知出典なら元の台帳と現在の原記録を維持する。生成費用は戻さない。予算停止や推論障害なら停止記録を残す。台帳を4K以内にするまで繰り返し生成しない。

source_idsが存在することは、doneの意味が正しいことや対象集合が完全であることの証明ではない。未実行操作を完了と誤記する可能性は残る。台帳は誤り得るという共通の説明を実行役に渡し、原文再読を許す。生成した台帳や認証値はローカルに保存し、公開するのは集計と全ファイルのハッシュだけ。

## 条件と費用

P11〜P13と同じ4開発課題、同じ順、同じモデル・公開API・実行役プロンプト・初期環境。各80 LLM呼び出し、80 API要求、450,000総入力＋出力、1,800秒、1生成4,096。台帳生成も総枠を消費する。

既存のInference実装ではFOCUS草案が温度0.7、台帳は実行役と同じ1.0を使う。P14でもこの既存条件を維持し、結果を見て生成中に変えない。推論モードも元のenabledを維持する。役割ごとのseed順序を使うが、固定seedによる同じ軌跡は保証しない。

まず同じモデルで情報表現と更新費用を比較する。小さい草案専用モデルや記憶役だけの推論モード変更は、別の条件として検証する候補であり、劣るから除いたわけではない。原FOCUSの小さい草案モデルの有効性を、この同一大型モデルの実験だけで反証しない。

## 実行前の検査と開始条件

原会話を変えないこと、過去の台帳・選択を後続更新で書き換えないこと、未知出典の棄却費用、保持生成が環境操作にならないこと、全費用と保存点・実入力を再計算できることを検査する。

拡張時に、ソーススナップショットのファイル名を誤って置換した不具合と、台帳方式を標準会話の初期化から外してしまう分岐漏れが見つかった。実行器の検査で検出し、両方を修正した。238検査合格時点ではP14のモデル生成・環境操作は0。

P13の完了後に保存済み4入力の計数、サーバーの残り稼働時間、ソースハッシュを確認して開始する。全試行と評価に必要な時間が足りないときは、そのサーバーで開始せず、実行中の試行がなくなってから稼働枠を更新する。条件を固定する前にP14を開始しない。

## 判定

10月21日11時台の停止確認後、開始前提の参照を`P13_recovery_v01`の終了へ変更した。P13の完了済み2件を維持し、中断した第3課題だけを新IDの初期実行として第4課題まで終える状態を待つ。P14の課題・モデル・予算・保持規則は変更しない。旧バッチ名を固定していた入力確認器と検査を、この同じ4課題の対応を検査した上で更新した。新サーバーの4時間枠でも、P14開始時に8100秒以上残ることを確認する。

全履歴、直近保持、FOCUS適合版と、最終成功・総費用・更新費用・原文再読・重複要求・不正な台帳を比較する。台帳で十分なら、その結果を独自機構の必要性が弱まる証拠として残す。失敗した課題だけ、成功した更新だけを選んで報告しない。

各条件1試行の4開発課題であり、品質同等性や大規模・長期作業の主評価を代替しない。最終評価は別プロセスで行い、その結果を後続のモデル入力へ返さない。
