# P110: 実行領収で推論履歴を選ぶ候補の入力計数

P109で実際の取得と入力増加を確認した後に準備する. 新規性と全仕事の削減は未成立であり、[先行５方式との確認範囲](../receipt_history_prior_scope_20261025.md)を前提にする. P99の既知４課題・全８実行を用い、148保存入力それぞれに３表示、計444入力を作る. 元の１生成の使用量不明と全未達を保持する.

## 変更するもの

モデルへ渡す過去assistantメッセージのreasoning_contentフィールドだけを選別する. system/user指示、assistant公開本文、提出コードと引数、tool結果、API実行順、予算通知、モデル設定は元の保存値を保持する. 原文の履歴は書き換えず、毎回そこから表示を作る.

| 条件 | 規則 |
|---|---|
| full | 全ての過去推論を表示する. |
| recent | 直近１回の推論を表示し、それ以前のreasoning_contentを表示から除く. 通常の固定窓対照. |
| execution_gated | 直近の手順が適格な場合だけ、同じく適格だった古い手順の推論を表示から除く. 直近の推論と、不適格な過去手順の推論は保持する. 直近が不適格なら全ての原文推論を再表示する. |

適格判定はホスト側の実行記録を使う. 非空の実API要求があり、全ての外側操作がrun_pythonとして正常終了し、内側の全要求が送信・正常返却されたと型付き領収で確認でき、未取得予約と出力途中切れがないことを要求する. 外側結果と内側領収の順序・件数・対応を照合する. 未送信、拒否、Python例外、API例外、作用不明、APIなしの局所計算、read_span等は適格にしない. stdoutに書かれた成功宣言は判定へ使わない.

適格な手順でも、保存された関数名・全引数と表示するassistantの関数列の指紋が一致しなければ保持する. 通信上のcall ID自体はこの指紋に含めない. text fallback等で対応できないものを適格へ補完しない. P99は通常の即時API経路で、ReadViewの遅延予約は存在しない. この入力計数にだけ予約０を明示する.

**これは意味的な不要性を保証する規則ではない.** 正常な実行にも未完了の計画が含まれ得る. 過去の失敗が後の成功で解決したとは自動判定せず、その推論は残す. 原文を戻せても、変更した履歴による誤判断を防ぐ保証にはならない.

## 計数と固定範囲

[設定](../../configs/P110_receipt_history_inputs_v01.json). 各保存境界で、それ以前に実際に記録された領収だけを使う. 未来の出力、正解、評価内容を選別へ使わない. 元のタスク実行はせず、未知の生成費用を補完しない. 各条件の元成否は既知の事後診断であり、独立確認ではない.

同じllama.cpp版、モデル語彙、実効chat template、要求parserで入力を数える. 語彙だけをロードし、推論contextの作成とdecodeは０. fullの入力計数を元の147正常応答の実測input tokenと照合する. 使用量不明の１要求も３表示を残すが、その新しい計数値を元の実消費へ代入しない. 表示間でdecoder制御と非メッセージ設定が変わっていないことを照合する.

各入力のtoken差、非表示・保持した推論の位置、直前の仮想表示との差、API実行の適格理由を記録する. 連続する仮想入力token列の共通接頭辞も記録するが、実際のcached token、課金、再処理時間とは呼ばない. 前の生成によるKV状態を再現したものではない.

元の履歴上で各境界を独立に変更する診断であり、新しい方針の後続出力は生成しない. 元の予算通知を残す. 仮想入力の差を全境界で合計しても、変更後の実軌跡や実現可能な仕事費用の削減にはならない.

全体600秒、rendererは条件ごと90秒、実測RSS上限２GiB. 入力ファイル16MiB、元の私有入力合計512MiB、各条件80保存生成・4,000イベントまで. 同じ完全headのpush/PR両workflowと両accounting-and-syntax job成功後に一度だけ実行する. `.runtime/P110.stop`とユーザーの停止に従う. 失敗、未計数枠、出力とログを保持し、自動再試行しない.

新しいモデル生成、API送信、生成コード実行、評価、DB内容、未見12課題の読取は０. 新しいモデル比較は、動作と適用範囲をこの診断で確認した後、全保持と直近保持を含む別の有限計画として固定する. 入力が短くなっただけでは採用しない. 原稿は引き続き保留する.
