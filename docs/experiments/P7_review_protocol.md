# P7の意味確認：出力を見る前に固定する記録形式

P7がP6の終了を待っている2026年10月21日05時台に、この補助仕様と検査を追加した。[実行前の分類規則](P7_memory_input_probe.md)を具体的な記録形式へ対応づける。生成条件・入力介入・回数・予算は変更しない。

この対話の助手が、モデルの提出した台帳と公開の実行記録を照合する。**人間専門家による確認、盲検評価、複数評価者の一致率を実施したとは扱わない。** 正解一覧・独立評価器・後続の操作を根拠に使わない。

対象は形式と参照の検査を通った全出力の全done項目。「未実行のターンだけを参照した項目」へ対象を限定しない。形式不適合の出力は、誤った完了が0件とは解釈せず、意味の測定対象として成立しなかったと示す。

各done項目について、以下を別々に記録する。

| 項目 | 記録する分類 |
|---|---|
| 主張の意味 | 操作完了／観測・調査完了／要求・対象の記述／判定困難 |
| 行為の種類 | 認証／対象変更／完了通知／文書取得／検索・読取／記述／判定困難 |
| 状態の支持 | 支持される／支持されない／判定困難 |
| 引用した証拠の支持 | 支持される／支持されない／判定困難 |
| 判定理由 | 成功観測／未実行／観測との矛盾／要求の記述／不十分な特定／別の有効な証拠／エラーの確認 |

根拠が別のターンにある場合は、状態が正しいが引用が不適切という分類を可能にする。未実行であっても、既に要求を満たすことを公開観測が示す場合や、単にエラーを確認したという意味なら無条件に誤完了としない。混在した主張は無理に断定せず判定困難を残す。

元要求のハッシュ、各応答のハッシュ、項目番号・ハッシュへ注釈を結び付ける。元の保存履歴に後続ターンが含まれていても、レビューへ渡すのは元要求に含まれる参照IDの時点まで。未確認の項目、重複した注釈、異なる出力への注釈、時点外の証拠があれば公開集計を拒否する。

本文・対象名・認証情報・推論文はローカルのレビュー資料に保持し、公開するのは上記の分類、件数、費用、ハッシュだけとする。[処理](../../scripts/review_memory_probe.py)と[対照検査](../../tests/test_memory_semantic_review.py)を記録する。

比較の単位は同じ1つの入力に対する種43・44・45。9個の独立した課題や、意味判断の正解データセットとは呼ばない。誤完了が減っても、環境で継続実行していないため最終タスク成功の改善とは言わない。
