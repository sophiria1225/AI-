# P54：公開契約に基づく３つの取得対照

## 目的と判定範囲

P53の２候補の継続生成は見送り、次は取得そのものを省ける範囲を確認する。既知P24の最大値課題で、**同じ公開境界から得た対象ID集合**に対する通常の個別取得・順位付き取得・限定した先行取得を比べる。新しいアルゴリズムの比較、自然言語の対象解釈、LLMの方式選択、タスク完了の比較ではない。LLM総tokenの削減も、この生成０の点検から主張しない。

原要求の意味を正解側から与えず、既に観測した `P24_06_GUIDED` の `call_004` 直後、５公開APIの境界を固定する。対象IDは `s5` のプレイリスト一覧中の `song_ids` の重複除去だけで作る。後続の詳細取得・回答・成功情報・評価器・DB内容は選択に使わない。既知記録で57 IDと確認済みであり、未調整評価ではない。

## 同じ入力を受ける３対照

| 対照 | 取得するもの | 終了条件と不利な条件 |
|---|---|---|
| point | 対象IDを元の順に１件ずつ `show_song` | 全対象の値を読む。対象数に比例する |
| ranked | 空の検索語・`-like_count` による `search_songs` の20件ページ | 全対象が既知、または観測済み最大値より順位境界が厳密に下がるまで進む。対象が低順位なら余計な取得が増える |
| bounded | 同じ順位付き取得を１ページだけ試し、不十分なら個別取得 | 先行ページ中の対象レコードを再利用。通常の個別取得に対し最大１要求分の追加がある |

最大値が同じ対象は**全て**返す。ページ末尾が同点なら先へ進む必要があり、最初の対象を見つけただけでは終了しない。検索語があるとページ内の順位に変わるため、その契約では順位による終了を使わず個別取得へ戻る。安定した同一状態が保証されない場合は全対照で未完了とする。観測した順序違反、重複ID、対象不在、欠損値、APIエラーでは回答を返さず失敗を保存する。

部品の契約は信頼するハーネスのアダプターが設定する。LLMが自己申告した「網羅」「並び順」を信頼する仕組みではない。観測済みページが並んでいても、未取得部分の順序や網羅を実測で証明できたことにはしない。[原典・公開実装との対応](../ranked_access_scope_20261022.md)。

## 固定した実行と予算

- `configs/P54_ranked_subset_access_v01.json`、実装・検査を含む清浄な確定コミットで実行する。３対照は point → ranked → bounded の順で各１回。別の新しい模擬環境を使う。
- 各対照の準備は元の５ APIのみ。公開スキーマ・５観測・保存DB13ファイルを元境界へ照合する。両取得APIの公開スキーマは元のアプリ説明要求で既に公開されている。
- 各対照は最大80取得要求、準備込み85、３対照合計255要求。対象数は最大100、順位ページ20件、boundedの先行取得は１ページだけ。結果を見て変えない。
- 各対照の本体180秒、全体本体600秒。各終了処理は15秒、強制終了後の回収５秒を別枠で上限化し、実際の全経過時間へ含める。時間切れも不採用条件として残す。
- 新しいモデル生成・token計数・評価器・保留12シナリオの閲覧は０。未完了や失敗の同条件再試行はしない。source／prefix不一致とAPI契約違反でバッチを止める。順位走査の固定取得予算到達だけは未完了として残し、次の予定対照へ進める。
- 読取ごとに保存DBのバイトハッシュが境界と同じことを確認する。内容を分析者や方式へ渡さない。これは保存ファイルの一致であり、任意の外部サービスの状態保証ではない。

## 全結果と採否

予定３条件・未実行・各API試行・全返却のUTF-8 byte・結果投影のbyte・時間・対象集合ハッシュ・結果ハッシュ・終了理由を保存する。共通５ APIの準備も全体費用に含める。実要求と返却、対象ID、答えは非公開の原記録に残す。

独立に全対象を読む point の最大値集合と他２方式を照合する。全件一致しても、この一つの既知集合についての取得部品の確認に限る。rankedとboundedが同じなら、boundedの追加価値を主張しない。同じ集約結果を返す対照間のAPI削減を、LLM入力・出力削減率へ換算しない。品質・総費用・独自性の主比較へ進めるには、その後に残る具体的な差が必要である。

検査は小さい全81値配置×15対象集合×３対照を独立した最大値計算へ照合し、同点・負担増・不適用・異常を含める。これは13個の部品検査を含む実装検証で、独立した研究課題3,645件として数えない。
