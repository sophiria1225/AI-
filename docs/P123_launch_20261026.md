## 同じMacの通常ターミナルで再開する

必要なモデル・AppWorld・実記録は既存の`/Users/tp26013/AI-`にある. 実行可能なローカル環境で、次を１回実行する. 新しい実験許可の再取得ではなく、現在のセッションから実行できない処理を承認済み環境で行うための手順である.

```sh
/Users/tp26013/AI-/.runtime/p3_ci_venv/bin/python /Users/tp26013/AI-/.runtime/finish_p123_prepared_20261026.py --execute
```

この私有launcherは、保存済みmanifestの完全head・tree・config・wrapper・collector指紋、clean tree、研究repo、旧プロセス、ローカル待受、ネットワーク、停止印・開始印を確認する. 次に固定branchをpushしてPRを作り、同じheadのpush・pull_request両CIと両jobの成功を待つ. 失敗時はモデルを開始しない. 成功後にmergeし、そのPR headに固定した実行木を作る. Project同期は既存の範囲確認付き処理を使う.

`--execute`なしでは環境と指紋の確認のみで、公開・生成しない. 起動済みの印、違うhead、途中失敗があれば自動再試行しない. その場合は状態を確認する. ターミナルは終了まで開いたままにする.
