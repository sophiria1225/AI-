# 単一エージェントの接続仕様

2026年10月13日のP1用。[mini-swe-agentの固定版](https://github.com/SWE-agent/mini-swe-agent/tree/04d809ceab9df28f9adaed044884180159172930)を`vendor/mini-swe-agent`へ取得した。バージョンは2.4.6、元のソースは未変更。P1は共通環境に合わせた接続であり、公式報告の性能・全設定の再現ではない。

## そのまま使う部品

- `DefaultAgent`：線形履歴、ステップ上限、形式エラー処理、軌跡保存。
- `BASH_TOOL`と`parse_toolcall_actions`：native tool callの構文検査。
- `format_toolcall_observation_messages`：可視実行結果の整形。
- `DockerEnvironment._check_finished`：先頭の完了マーカーと終了コードによる提出判定。
- `config/benchmarks/swebench.yaml`の調査・再現・実装・確認の基本手順。

## 共通研究環境のための変更

| 項目 | P1での処理 | 理由・限界 |
|---|---|---|
| モデル接続 | 自前アダプターでOllama `/api/chat`を使用 | 各ストリームの末尾使用量を直接保存。LiteLLMや外部APIの課金換算は使用しない |
| Python | testbedのPATHを指定し、起動時にprefixとimportを確認 | 毎回のactivationを省く。以前のコア生成原因を証明した意味ではない |
| コンテナ | 固定イメージ、ホストマウント無し、ネットワーク無し、共通のCPU・メモリ等の制限 | 公式の既定コンテナ設定と同一ではない |
| shell | 45秒の上限、pipefail、出力を最大10,000文字表示 | パイプ途中の失敗を隠さず、費用増加を制限する |
| 作業範囲 | 要求に必要なソース・テスト・設定の変更を許可 | E0と権限をそろえ、比較側を意図的に弱くしない |
| 提出 | 完了宣言または予算終了時の作業ツリー差分を凍結 | モデルによるpatch.txtの選別には依存しない。未完了試行も独立評価する |
| 作業ファイル | `.harness_notes`と未追跡ELF coreを除外、理由を記録 | 新規ソースとテストは維持。すべての未知の不要ファイルを判別できるわけではない |
| 生成上限 | 4,096出力トークン。lengthなら実行せず終了 | 不完全な応答を完成した手順として扱わない。改善のための自動再試行はこの版に無い |
| 予算 | 最大30呼び出し、入力＋出力300,000、15分 | 単一入力上限65,536とは別。残量の保守的な事前検査と実使用量を併記 |
| 推論モード | 両モデルともthinking無効、temperature 0、seed 7 | 生成を実際の操作まで到達させる校正条件。各モデルの最良設定という主張はしない |

総トークンには形式エラー、失敗した操作、意図的な打ち切り試験も含める。キャッシュ入力は入力の内数で二重加算しない。mini内部のドル費用カウンターは使用せず、ローカル実行のドル費用は未測定として記録する。

各実行フォルダに、実行器・接続部品のソース、設定、実際のプロンプト、モデル要求／応答、ツール入出力、軌跡、最終パッチとSHA-256を保存する。必要な上流部品のコミットとハッシュは`records/sources/P1_mini_pinned_source.json`に残す。

## 評価の読み方

P1の2モデルは同じ基盤・実行器・予算枠で比較するが、モデル構造、重み、トークナイザー、推論速度は異なり得る。トークン数の違いをそのまま計算量比と呼ばない。モデルをまたいだ比較は候補選定であり、ハーネスの削減効果の主張には同じモデルでの比較が必要。

初回E0との比較では実行器、プロンプト、thinking設定、呼び出し枠、環境起動方法が同時に変わっている。原因を一つに絞る比較ではない。P1の未調整確認用課題は0件で、すべて開発用として扱う。
