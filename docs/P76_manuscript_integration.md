# P76を原稿へ含める範囲

P76の閉じた全８条件を、過去の表示比較とは別の通常履歴比較として追記する。両方2/4成功、写真の局所的な仕事token減少、精算・返金の増加、書出しの両未達と不明使用量を全て示す。初回入力の増加と仕事全体費用を分け、固定採用基準の未達を保持する。

全条件表と文は `scripts/build_reasoning_comparison_report.py` が監査から生成する。全８評価・不明２生成を表へ残し、成功例だけを中心結果へ切り出さない。P76の新しい43生成・既知588,495 token＋不明２生成、408 API、８評価を別記する。共通前半の再掲を新しい生成へ加えない。

推論保持・削除と後続経路の関係を扱うWangほかの原典を文献へ追加する。[確認範囲](reasoning_retention_overlap_20261023.md)と[全９著者の書誌](../reports/letter_reasoning_reference_20261023.json)を残す。ICLRは方式名であり会議採録の表示ではない。

原稿生成は `scripts/build_reasoning_comparison_paper.py` を入口にし、従来の全結果検査を引き継いでから、閉じたP76・全件CSV・資料・本文部品の対応を確認する。主張を支える範囲は同じ既知４課題・各１回の探索比較のままである。一般的な非劣性、新手法、採録に足る中心貢献は成立済みとしない。

[P76反映前の原稿](../papers/202610_letter/archive_before_P76_20261023/README.md)を保存した。組版・全ページ確認の結果は現行原稿のsource mapとlayoutへ記録する。公式クラスの最新版との一致、著者情報、投稿可能な完成版は別に未完了として扱う。
