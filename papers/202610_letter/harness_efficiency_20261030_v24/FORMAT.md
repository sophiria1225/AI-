# 組版と投稿形式

v24の主成果物は、ユーザー書式を保持したv23 Word原稿を直接編集したmanuscript.docxである。元の系統は電子情報通信学会の公式和文Dレターテンプレートiss_lettertemplete.docxに基づく。公式配布部品とのbyte一致を新たに主張せず、直前版からの段落移動と限定した文字列変更を検査する。

3.1の導入を3節概要の末尾へ移し、3.1見出しを図1・図題の後へ移動した。3節概要の文章を増やし、3.1で同じ内容を繰り返さない。あらましは120字、英文要旨は39語である。日英題名、著者3名、所属、連絡先を保持し、フォント・字間・余白を変えてページ数を調整しない。

TeX版は1頁目を3節概要までとし、2頁目の上端に図1を配置して、その下から3.1を開始する。図は浮動させず、既存クラスの段抜き領域とキャプション機能を用いる。TeXの著者はユーザー原稿と同様に1名1行に配置し、字体や余白は固定クラスのものを用いる。classは既存のv3.4a固定mirrorを利用し、新たに最新版の認証を行ったものではない。

Word版の編集用ソースはmanuscript.docx自体である。render_word.pyはPDF校正だけを行い、DOCXの指定字体を変更しない。MacにMS明朝がないため、参考PDFではHiragino Mincho ProN／Hiragino Sansの代替を明示する。Microsoft Word本体の最終改ページは未確認であり、校正PDFのページ数をWord本体の値とは扱わない。参考校正PDFは本文・文献7頁と英文要旨1頁、TeX版は本文・文献6頁と英文要旨1頁である。LibreOfficeでは概要が1〜2頁、図1と3.1が3頁となり、文献11のDOIが7頁へ続く。

Word表2点は編集可能であり、数式はOMML、図1は1画像である。図1は130×97 mm、最小文字サイズ7 pt、役割ごとの淡い青・橙・白と黒い文字・枠線を保つ。図表キャプションは番号と短い名称だけとし、結果グラフを追加しない。Excel表と図のデータ・生成コードはv23から変更しない。

既存版で2026年10月30日に確認した[和文論文誌投稿のしおり](https://www.ieice.org/jpn/shiori/iss_2.html)では、レターの標準は2頁、初回投稿が本文・文献5頁以上の場合は超過理由書を添付して審議を受ける。末尾添付の英文あらまし・キーワードは標準頁数に含めない。提出するWord/PDFのページ数と掲載先固有の条件を確認する。投稿は行っていない。

テンプレートに残る巻号・年・ページ番号などの未確定表示は投稿前に確認する。公開コードURLは https://github.com/sophiria1225/AI- であり、Word脚注とTeXのリンクに同じ末尾ハイフンを含む全文を保持する。
