# 組版と投稿形式

v18 の manuscript.docx は、電子情報通信学会の公式「情報・システム／レター」テンプレート iss_lettertemplete.docx を基に作成する。テンプレートのSHA-256は 1b5b574780cfb971897bea26d07b9dd84a6f523124664a5bf6b84ea3fee75709、70,877 bytesである。公式styles.xml、fontTable.xml、settings.xml、全ヘッダー・フッター部品をbytes単位で保持する。著者・所属・連絡先は未設定とし、架空の情報を補わない。

本文8.5 pt、文献・キャプション7 ptの元スタイルを変更しない。編集可能な2表は幅65 mm、7 pt・行間10.8 ptとし、数値を右揃えにする。方式名の見出しは「専用1回／方式」「専用反復／方式」「行動併記／方式」の意味の切れ目で改行する。表2は「終了制御」を介入条件、「通常継続」を比較条件とする。本文の「完了判定」は終了制御内の検査段階を指す。図表キャプションには番号と短い名称だけを置く。

テンプレートのB5用紙、上下1418・左右851 twips、段間443 twips、docGrid linePitch266を保持する。図1は幅130 mmの両段図として頁上端に置き、図の後は連続した2段組とする。結果は表1・表2だけで示し、結果グラフを置かない。図1の字形・矢印を原寸と拡大表示で確認する。実寸は130×97 mm、最小文字サイズは7 ptであり、図のmanifestに記録する。

3.3の式の導入・数式・最初の集計説明を同じ段に保持する。Word数式はOMMLとし、式番号(1)を右揃えタブで独立して配置する。本文の量記号は編集可能な斜体・下付き文字とする。見出しを次の本文と保持し、孤立した末尾を避ける。ページ数合わせのためにフォント・字間・余白を縮めない。

題名は「LLMエージェントにおける履歴要約方式と／終了制御の総トークン数評価」と意味の切れ目で改行する。日本語あらましは116字、英文要旨は39語、キーワードは日英各5語である。英文要旨・キーワードは末尾の独立頁に添付する。

2026年10月30日に確認した[和文論文誌投稿のしおり2.3](https://www.ieice.org/jpn/shiori/iss_2.html)では、レターの標準は2頁であり、初回投稿が本文・文献5頁以上の場合は超過理由書を添付して審議を受ける。英文あらまし・英文キーワードの末尾添付は標準頁数に含めない。最終PDFはWord・TeXとも本文・文献5頁と英文1頁であり、初回投稿には超過理由書が必要となる。実測値をtypesetting_validation.jsonに記録する。

校正PDFはLibreOffice 26.8.1のローカル変換による。MacにMS明朝がないためPDFではHiragino Mincho ProN／Hiragino Sansへ代替し、DOCXの公式フォント指定は変えない。Microsoft Word本体の改ページ一致は確認していない。Excel表もMicrosoft Excel本体での描画とLibreOfficeでの検査を区別する。WordとTeXの最終全頁を個別に目視し、埋込みフォント、図、表、式、段の読み順と孤立行を検査した。

図1は三方式で同じターン区間を示し、要約機会上限と採否判定の時点をそろえて比較する。図内の検査項目と全履歴保存の説明枠は外し、本文3.1の説明を保持する。採用後の入力は要約と未要約の全履歴であり、直近2ターンだけに固定しない。要約の採否検査は構造・文字数・入力短縮について行い、内容の正しさを保証する検査とは扱わない。実験Bの完了判定は既知の一つの要求形式に対応する手書き規則であり、実験Aとは独立に評価する。

公開URLは https://github.com/sophiria1225/AI- で末尾のハイフンまで正確に記す。Word脚注に外部リンクの関係を設定し、TeXはhyperrefのurlリンクとして出力する。ieicejの引用番号処理を保持するため、hyperrefの文献処理の変更を無効にし、数値引用の体裁を変えない。元テンプレートの誌名・巻号・頁・年等の未確定表示は保持し、投稿前に実情報の確認が必要である。
