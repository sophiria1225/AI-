# v19 改訂記録

文章の説明順と文体を修正した。図1、表1・表2、実測値、全条件、12文献、Excel表はv18から変更していない。日本語あらましは115字、英文要旨は39語である。

| 変更 | 理由 | 主張との整合 |
|---|---|---|
| 3.1の専用1回方式の上限と0回の可能性を明示 | 最大1回と必ず1回を区別する | 機会上限1・3・3と既存の採用回数を保持 |
| 反復方式の要約対象を肯定形で定義 | 対象を直接説明し、口語的な否定表現を減らす | 不採用時に残る未要約履歴も対象とする |
| 機会数・採用回数・モデル呼出し数を区別 | 呼出し配置の比較を読み取りやすくする | 行動併記に要約専用呼出しを追加しない |
| 3.2の確認手順を分文 | 入力記録、全対象の照合、完了APIの順を明確にする | 実行・記録後、初めて充足した時点に1回通知 |
| 5.1に完全先頭一致基準の目的を置く | 結果より前に比較方法を説明する | 事前計画と監査スクリプトに基づく |
| 5.2で一致と不一致を区別 | 最終状態の一致と生成過程の完全一致を混同しない | 全文の完全一致不成立と各1回の限定を保持 |
| あらまし・結論の文末を整理 | 過去形の反復を減らし、評価の意義を示す | 既知条件での観測と独立A/B評価に限定 |

和文句読点は「．」「，」を維持した。旧版の指摘箇所では読点への変換を再現しなかった。v19の組版中にはWord由来PDFの結論で句点1字の欠落を検出し、文意を保つ短縮と再出力で修正した。最終版は源データと両PDFを2種類の文字抽出器と拡大字形で確認した。フォント・余白・字間は変更していない。

新しい実験、成功判定の変更、データの補完は行っていない。12.07%の差がCSV処理のみで生じたこと、要求・応答全文の完全先頭一致が不成立だった事実、既知課題・少数試行・事後整理という範囲を保持する。

著者・所属・会員情報、掲載先固有の規定、投稿用の巻号等の扱いは引き続き確認が必要である。Word・TeXとも本文・文献5頁と英文1頁であり、初回投稿には超過理由書が必要となる。Microsoft Word本体の改ページ一致とMicrosoft Excel本体の描画は未確認である。
