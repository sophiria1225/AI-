# 公式 Word テンプレートと組版条件

v10 の `manuscript.docx` は、電子情報通信学会の[公式テンプレート一覧](https://www.ieice.org/jpn/shiori/template.html)の「情報・システム／レター」で配布される `iss_lettertemplete.docx` を基に作成した。固定SHA-256は `1b5b574780cfb971897bea26d07b9dd84a6f523124664a5bf6b84ea3fee75709`、70,877 bytes。本文例は除去し、著者・所属・連絡先は未設定とする。

公式 `styles.xml`、`fontTable.xml`、`settings.xml`、全ヘッダー／フッター部品をbytes単位で保持する。本文8.5 pt、文献・キャプション7 ptという元スタイルの定義を変更しない。表は編集可能なWord表、幅65 mm、7 pt・行間10.8 pt、数値右揃えとする。見出しの意味の区切りで改行し、数値や短い単語を不自然に分割しない。本文に字間圧縮を適用しない。

実テンプレートXMLはB5（10319×14572 twips）、上下1418、左右851 twips、2段間443 twips、docGrid linePitch266であり、これを継承する。図1は130×65 mmの両段図を2頁上端に置き、和英キャプションを含む領域の後を連続した2段へ戻す。図2・図3は各65×58 mmの片段図で、それぞれ実験A・Bの結果に対応する。図内の最小文字サイズは7 ptで、PDF/SVG/EPSは字形をベクタ輪郭として保存する。末尾英文は独立頁に添付する。

3.2の導入文、総和式、その最初の説明は同じ段に置く。Word数式はOMMLのまま、式番号(1)を独立した右揃えタブで段右端に置く。本文中の変数は通常の編集可能な斜体・下付き文字として本文ベースラインへ揃える。見出しを次の本文と保持し、長い段落は孤立行を避けつつ段間の分割を許す。タイトルは「終了制御による／実行費用の評価」で改行する。

[現行の和文D投稿規程2.3](https://www.ieice.org/jpn/shiori/iss_2.html)ではレターの標準は2頁で、初回投稿が5頁以上の場合は超過理由書を添付して審議を受ける。末尾の英文あらまし・英文キーワードは標準頁数に含めない。テンプレート中の古い「5頁以上不可」の説明と現行規程を混同しない。今回はページ数を固定しないという編集指定に従い、文章・図表の読み順を優先した。Word校正PDFとTeX版はいずれも本文・文献4頁＋英文1頁である。将来の改稿で本文が5頁以上となる場合は、初回投稿の超過理由書が必要となる。

和文あらまし103字、英文あらまし40語（保守的分割）、キーワードは各5件。実測数値、成功・失敗、課題数、実行数、採用数、閾値、モデルと予算、要求・応答全文の先頭部分完全一致が不成立だった事実、事後整理の限定を維持する。図1の上端配置は今回の編集指定であり、学会が全段抜き図を一律に禁止するという意味ではない。

校正PDFはLibreOffice 26.8.1のローカル変換による。MacにMS明朝がないためPDFではHiragino Mincho ProN／Hiragino Sansへ代替し、DOCXの公式フォント指定は変えない。Microsoft Word本体との改ページ一致は確認していない。Word全5頁、TeX全5頁を個別に目視し、日本語、式、図表・キャプション、表内の改行、見出し直後の本文、短い孤立行、はみ出しを検査した。全PDFフォントは埋込み済みである。

`manuscript_tex.pdf` は同じ本文・実験値を組んだ別のTeX版で、Word出力ではない。固定 `ieicej.cls` はv3.4aのミラー、SHA-256 `36b2731a97ecbb86f02b1aff50cf38d10ae57c6f1a6448f5fc9956226412a56a`。Word公式テンプレートの取得をもってTeX最新版まで確認したとは扱わない。最終TeXのはみ出し警告と未解決参照はともに0。追加比較の補足PDFは独立したarticle形式であり、学会による補足形式の承認を示さない。

出版年月・巻号等のプレースホルダーは保持し、架空の発行情報や著者を補わない。本文への新しい実験結果の追加はない。履歴上の旧図・候補図はv08に保持し、本版には使用する3図だけを同梱する。

本版では独立した「考察と限界」を削除し、あらまし・実験結果・第6節の結論を達成事項から説明する。本文の適用範囲は末尾の短い段落、Inlineの比較と厳密prefix不成立は各結果節へ残す。実験値・条件・3図・12文献を更新する変更ではない。
