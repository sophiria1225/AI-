\begin{abstract}
LLMエージェントの履歴を反復要約する制御と，実行記録から完了を判断する制御を個別に評価した．要約処理も含む全呼出しを計測し，既知課題で成功を保ちながら，履歴の再入力や完了後の不要な生成によるトークン消費を抑えられることを示した．
\end{abstract}
\begin{keyword}
LLMエージェント，ハーネス，履歴要約，終了制御，費用評価
\end{keyword}
\begin{eabstract}
We separately evaluate controls that repeatedly summarize interaction history and judge completion from execution records. Counting all model calls, including summarization, we show that these controls can reduce token consumption from repeated history input or unnecessary post-completion generation while retaining success on known tasks.
\end{eabstract}

\end{ekeyword}
