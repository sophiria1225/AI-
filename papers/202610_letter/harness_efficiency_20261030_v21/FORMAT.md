# 組版と投稿形式

v21 の manuscript.docx は、電子情報通信学会の公式「情報・システム／レター」テンプレート iss_lettertemplete.docx を基に作成する。テンプレートのSHA-256は 1b5b574780cfb971897bea26d07b9dd84a6f523124664a5bf6b84ea3fee75709、70,877 bytesである。公式styles.xml、fontTable.xml、settings.xml、全ヘッダー・フッター部品をbytes単位で保持する。著者・所属・連絡先は未設定とし、架空の情報を補わない。

本文8.5 pt、文献・キャプション7 ptの元スタイルを変更しない。編集可能な2表は幅65 mm、7 pt・行間10.8 ptとし、数値を右揃えにする。方式名の見出しは「専用1回／方式」「専用反復／方式」「行動併記／方式」の意味の切れ目で改行する。表2は「終了制御」を介入条件、「通常継続」を比較条件とする。本文の「完了判定」は終了制御内の検査段階を指す。図表キャプションには番号と短い名称だけを置く。

テンプレートのB5用紙、上下1418・左右851 twips、段間443 twips、docGrid linePitch266を保持する。図1は幅130 mmの両段図として頁上端に置き、図の後は連続した2段組とする。結果は表1・表2だけで示し、結果グラフを置かない。図1の字形・矢印を原寸相当と拡大表示で確認した。実寸は130×97 mm、最小文字サイズは7 ptであり、図のmanifestに記録する。

3.3の式の導入・数式・最初の集計説明を同じ段に保持する。Word数式はOMMLとし、式番号(1)を右揃えタブで独立して配置する。本文の量記号は編集可能な斜体・下付き文字とする。見出しを次の本文と保持し、孤立した末尾を避ける。ページ数合わせのためにフォント・字間・余白を縮めない。

題名は「LLMエージェントにおける履歴要約方式と／終了制御の総トークン数評価」と意味の切れ目で改行する。日本語あらましは115字、英文要旨は39語、キーワードは日英各5語である。英文要旨・キーワードは末尾の独立頁に添付する。

2026年10月30日に確認した[和文論文誌投稿のしおり2.3](https://www.ieice.org/jpn/shiori/iss_2.html)では、レターの標準は2頁であり、初回投稿が本文・文献5頁以上の場合は超過理由書を添付して審議を受ける。英文あらまし・英文キーワードの末尾添付は標準頁数に含めない。LibreOfficeで出力した参考校正PDFは本文・文献6頁と英文1頁、TeX版は本文・文献5頁と英文1頁である。Microsoft Word本体の頁数は未確認であり、提出原稿の本文・文献が5頁以上の場合は超過理由書が必要となる。実測値をtypesetting_validation.jsonに記録する。

校正PDFはLibreOffice 26.8.1のローカル変換による。MacにMS明朝がないためPDFではHiragino Mincho ProN／Hiragino Sansへ代替し、DOCXの公式フォント指定は変えない。Microsoft Word本体の改ページ一致は確認していない。Excel表もMicrosoft Excel本体での描画とLibreOfficeでの検査を区別する。両PDFの全頁で内容表示、埋込みフォント、図、表、式と句読点を確認した。LibreOffice参考校正PDFの図前の少量頁は、下記の制約として区別する。

図1は三方式で同じターン区間を示し、要約機会上限と採否判定の時点をそろえて比較する。図内の検査項目と全履歴保存の説明枠は外し、本文3.1の説明を保持する。採用後の入力は要約と未要約の全履歴であり、直近2ターンだけに固定しない。要約の採否検査は構造・文字数・入力短縮について行い、内容の正しさを保証する検査とは扱わない。実験Bの完了判定は既知の一つの要求形式に対応する手書き規則であり、実験Aとは独立に評価する。

公開URLは https://github.com/sophiria1225/AI- で末尾のハイフンまで正確に記す。Word脚注に外部リンクの関係を設定し、TeXはhyperrefのurlリンクとして出力する。ieicejの引用番号処理を保持するため、hyperrefの文献処理の変更を無効にし、数値引用の体裁を変えない。元テンプレートの誌名・巻号・頁・年等の未確定表示は保持し、投稿前に実情報の確認が必要である。

図1の色は役割の識別を補助する。行動生成の呼出しと実験Bの次の生成は淡い青、要約専用の呼出しは淡いオレンジ、ハーネス処理は白である。斜線と円形の繰返し記号は使わず、反復可能な2方式は「要約機会：条件成立時，最大3回」と記す。黒の枠・文字・矢印と処理名で役割と流れを読み取れるようにし、色だけに依存しない。

2026年10月30日に再確認した[公式投稿のしおり2.5(c)(e)(g)](https://www.ieice.org/jpn/shiori/iss_2.html)では、カラー図の提出が認められ、両段図は13 cm、原寸の文字は約7 ptが目安とされる。白黒印刷では黄色系の濃度不足にも注意が必要なため、本図は背景色が薄くなっても黒い輪郭・文字・処理名を残す。図のサイズは130×97 mmを維持し、フォントを縮小しない。

和文本文の句読点「．」「，」と、v19で修正済みの結論の句点を保持する。v21では新しい216字段落を追加し、源データと両PDFを改めて照合した。図1と図表題はv20と同一である。

今回の主成果物はWord原稿である。ユーザーのMicrosoft Wordでは1頁目右段に約10行分の不足が報告された一方、この環境にはMicrosoft Word本体とＭＳ明朝がなく、代替フォントによるLibreOffice校正では不足が約2行だった。表示差の原因とWord本体での最終改ページは確定していない。

216字を追加するとLibreOfficeでは図前の本文が2頁目に少量続き、図1は3頁目上端へ移る。3.1節を図後へ送る試作でも少量頁は解消しなかったため、提出用Wordを優先し、追加した文章と3.1の元位置を保持した。字体・字間・余白・公式グリッドは変更していない。したがって、参考校正PDFの7頁をMicrosoft Word本体の頁数とは扱わず、印刷用の最終組版を確認済みとも扱わない。
