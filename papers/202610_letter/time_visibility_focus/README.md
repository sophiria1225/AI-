# 中心の問いを絞った別稿

終了したP80を中心に構成する[作業案PDF](draft.pdf)。本文・文献２頁＋英文１頁で、全３頁を目視し、はみ出し・未解決引用０。現在の主原稿 `candidate_cost_completion.pdf` を置き換えない。日英題名は教授用の合意案を維持する。

全８条件の監査と推論器停止を確認して全行を取り込んだ。M/Hはともに3/4成功だが、Hの書出しに使用量不明１回があり、全体の採用基準は未達。全件の成否・既知費用・不明費用・実時間を載せ、良かった３課題だけで改善を主張しない。本文要旨は93字、英文は44語。教授用456字とは別である。

狙いは「実期限が同じでも、ハーネスの時間通知が経路と全仕事費用へ関わるか」という限定的な実証である。表示と強制の分離や参照IDの正規化自体を新規アルゴリズムとはしない。４既知課題・各１回では一般的な品質維持や採録に足る根拠が弱いことを残す。反復・未調整群へ進む場合は、対象を開く前に問い、規則、対照、予算、採否、欠測処理を別途固定する。

旧主稿の全表示比較や終了制御は、閉じた主稿・原記録に保持する。本別稿では「旧比較がなかった」扱いにせず、探索経緯と開発群の既知性を明示する。教授用456字あらまし、著者欄、投稿先情報は変更しない。

[表の生成](../../../scripts/build_time_visibility_draft.py)と[別稿の描画](../../../scripts/render_time_visibility_draft.py)を分けた。生成後の本文へのモデル・runtime情報の追記はmanifestへ記録し、数値表は変更していない。著者未設定・公式様式未使用の検討稿で、投稿可能な最終稿とは扱わない。
