# 組版と投稿形式

v23の主成果物は、ユーザー提供の manuscript (9).docx を直接編集したWord原稿である。元の系統は電子情報通信学会の公式和文Dレターテンプレート iss_lettertemplete.docx に基づく。v23では公式配布部品とのbyte一致を新たに主張せず、ユーザーがWordで保存した文書のスタイル・段落設定・フォント・余白・段組・グリッド・図表・数式を保持したことを検査する。

変更は冒頭2段落の文字列だけである。あらましは120字、英文要旨は39語。ユーザーが入力した日英題名、著者3名、所属、連絡先を維持する。本文・文献・図表のフォントを縮小せず、字間・余白を変えてページ数を調整しない。

元原稿と同じLibreOffice 26.8.1環境、同じ代替フォントで比較し、対象段落が9→7行、10→6行となることを確認した。合計6行の減少はこの校正環境での値であり、Microsoft Word本体の測定ではない。Wordの実際の1頁目の最終行位置は未確認である。校正環境で1頁に収めるために追加削減した旧ローカル版は採用しない。

Word参考PDFは本文・文献6頁と末尾英文1頁、TeX版も本文・文献6頁と末尾英文1頁である。TeX版は同じ文章を別に組版したもので、Wordの改ページを再現するものではない。TeXの著者はユーザー原稿と同様に1名1行に配置し、字体や余白は固定クラスのものを用いる。classは既存のv3.4a固定mirrorを利用し、新たに最新版の認証を行ったものではない。

Wordの編集用ソースはmanuscript.docx自体とし、旧版のWord生成スクリプト・中間JSONを除いた。render_word.pyはPDF校正だけを行い、DOCXの指定字体を変更しない。MacにMS明朝がないため、参考PDFではHiragino Mincho ProN／Hiragino Sansの代替を明示する。

Word表2点は編集可能であり、数式はOMML、図1は1画像である。図1は130×97 mm、最小文字サイズ7 pt、役割ごとの淡い青・橙・白と黒い文字・枠線を保つ。図表キャプションは番号と短い名称だけとし、結果グラフを追加しない。Excel表と図のデータ・生成コードはv22から変更しない。

既存版で2026年10月30日に確認した[和文論文誌投稿のしおり](https://www.ieice.org/jpn/shiori/iss_2.html)では、レターの標準は2頁、初回投稿が本文・文献5頁以上の場合は超過理由書を添付して審議を受ける。末尾添付の英文あらまし・キーワードは標準頁数に含めない。提出するWord/PDFのページ数と掲載先固有の条件を確認する。投稿は行っていない。

テンプレートに残る巻号・年・ページ番号などの未確定表示は投稿前に確認する。公開コードURLは https://github.com/sophiria1225/AI- であり、Word脚注とTeXのリンクに同じ末尾ハイフンを含む全文を保持する。
