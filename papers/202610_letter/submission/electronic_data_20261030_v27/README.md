# 提出項目2：原稿・図表の電子データ

[電子データZIPをダウンロード](submission_electronic_data.zip)

17件のコメントを反映した原稿を収録しました。原稿調整中のため、現時点の **v27を収録した準備版** です。印刷見本の原稿PDFに対応する提出項目1は、このZIPには含めていません。

`electronic_data/` に、Word原稿、図1のPNG・SVG・PDF・EPSと作図コード、Excelの結果表と元データ・生成コード、参考LaTeXソースを整理しています。図単体のPDFは、図の電子データとして収録しています。原稿本文・図表・実験値はv27から変更していません。

容量上限は10MBを **10,000,000バイト** として扱い、ZIPと展開後の合計の両方を確認します。画像の解像度は維持しています。実際の容量とファイル一覧は [package_manifest.json](package_manifest.json)、各ファイルの用途は [収録案内](electronic_data/README.txt) に記載しています。

最終稿が確定したら `electronic_data/manuscript.docx` を差し替え、同梱した参考LaTeXも最終稿に合わせてください。その後、次のコマンドでZIPと容量・ハッシュ一覧を更新できます。

```sh
python3 build_archive.py
```

ZIPは明示した16ファイルだけから作成します。原稿PDF、旧版、実験ログ、検査用資料、フォント本体、他者の例示原稿は入りません。図表を追加した場合は `build_archive.py` の `FILES` 一覧も更新してください。

Wordが編集用の主原稿です。Wordと参考LaTeXは自動同期されません。最終稿と印刷見本PDFの一致は原稿調整後に確認する必要があります。提出先へのアップロードは行っていません。
