# 公式 Word テンプレートと組版条件

v06 の `manuscript.docx` は、電子情報通信学会の[公式テンプレート一覧](https://www.ieice.org/jpn/shiori/template.html)で「情報・システム／レター」として配布される `iss_lettertemplete.docx` を土台に作成した。テンプレート SHA-256 は `1b5b574780cfb971897bea26d07b9dd84a6f523124664a5bf6b84ea3fee75709`、70,877 bytes。公式ファイルの本文例は削除し、著者・所属・連絡先は未設定とする。

公式 `styles.xml`、`fontTable.xml`、`settings.xml`、全ヘッダー／フッター部品を bytes 単位で保持する。適用スタイルは `研究速報_タイトル（和）`、`研究速報_タイトル（英）`、`共通_本文`、`共通_節見出し`、`共通_文献`、`共通_キャプション` 等。本文8.5 pt、文献・キャプション7 ptという元の定義を変更しない。テンプレート中の未適用「レター」スタイルへ置き換えない。

実ファイルの XML は B5（10319×14572 twips）、上下1418、左右851 twips、2段間443 twips、docGrid linePitch266。説明文の用紙・余白表記と一部異なるため、実 XML の値を継承する。図の領域だけ連続セクションで両段にし、本文は2段へ戻す。表は幅71 mmの片段内に収め、共通_文献の7 pt・行間10.8 ptを使用する。表内のみ字下げとグリッドへの吸着を解除し、文字列は左揃え・数値は右揃えとする。小表と和英キャプションを同頁に保つ。図は130 mm幅で、元の最小7 pt設計を維持する。末尾英文は元テンプレートと同じく改ページして2段のまま添付する。

[現行の和文D投稿規程](https://www.ieice.org/jpn/shiori/iss_2.html)では、レターの標準は2頁、初回5頁以上には超過理由書と審議が必要である。英文あらまし・英文キーワードは末尾に添付し、標準頁数に含めない。テンプレートの古い説明にある「5頁以上不可」と現行規程を混同しない。和文あらまし118字、英文は41語（保守的分割46語）、キーワードは各5件である。

校正 PDF は LibreOffice 26.8.1 のローカル変換による。Mac に MS 明朝がないため、PDF 表示は Hiragino Mincho ProN（明朝）／Hiragino Sans（ゴシック）へ代替される。DOCX の公式フォント指定は変更しない。Microsoft Word そのものの表示と同一であるとは認証していない。本文・文献4頁＋英文1頁の計5頁を全頁目視し、表題と表の同頁配置、数値の非分割、図の約7 pt文字、ページ外のはみ出しなし、全PDFフォントの埋込みを確認した。詳細は word_render_validation.json に記録する。

`manuscript_tex.pdf` は v05 と同じ内容の TeX 版であり、今回の Word から出力したものではない。TeX 版の固定 `ieicej.cls` は v3.4a、SHA-256 `36b2731a97ecbb86f02b1aff50cf38d10ae57c6f1a6448f5fc9956226412a56a`。Word 公式テンプレートの取得によって TeX クラス最新版まで確認したとは扱わない。補足表は独立した一般 article 形式であり、学会による補足形式の承認を示さない。

出版年月・巻号・頁の `XXXX` 等は公式テンプレートの未定プレースホルダーを保持する。フッターの頁番号は PAGE フィールドで、校正変換時に更新される。架空の発行情報や著者を補わない。v05 の実験結果と既存2図を維持し、新規実験の未閉鎖結果や未選択の4図候補を本文へ追加しない。
