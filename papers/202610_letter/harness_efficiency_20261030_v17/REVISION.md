# v17 改訂記録

| 変更 | 理由 | 主張との整合 |
|---|---|---|
| 題名を総トークン数の評価へ変更 | 金銭費用・時間との混同を避ける | 計測対象と一致 |
| 三方式の名称と初出説明を変更 | 呼出しの分離・共有と要約機会上限を読み取れるようにする | 機会上限1・3・3、採用回数、実呼出し数は別々に保持 |
| 終了制御と完了判定を区別 | 機構の名称と検査段階の混同を避ける | 比較条件は通常継続と終了制御 |
| 結果を2表に集約 | 同じ数値を示す棒グラフとの重複を減らす | 全実測値と成功結果は不変 |
| 図1を三方式の時系列と独立Bへ変更 | 行動併記で専用呼出しを追加しないことと採否の順序を示す | 元の履歴保存、未要約履歴の継続、共通検査を維持 |
| あらまし116字・英文39語に変更 | 評価内容と既知条件下の成果を明示する | 一般的な品質保証や組合せ効果を主張しない |
| 公開URLをリンク化 | 原稿から正しいリポジトリへ移動できるようにする | 末尾のAI-を変更しない |

専用反復方式の12.07%減はCSV処理だけの差であり、他3課題の改善として広げない。行動併記方式は写真操作では10,497トークン少ないが、専用反復方式に対して合計では6.53%多い。終了制御の26.00%減と30.15%減は二つのAPI条件それぞれの値であり、合算しない。要求・応答全文の先頭部分の完全一致が成立しなかった事実、既知課題・少数試行・事後整理という範囲を維持する。

ユーザー提供PDFはv14と同一であり、v16で確認済みの詳しい説明を保持して今回の指示を反映した。新しい実験、成功判定の変更、データの補完は行っていない。

残る確認は、著者・所属・会員情報、掲載先固有の規定、投稿用の巻号等の扱いである。最終PDFはWord・TeXとも本文・文献5頁と英文1頁であり、初回投稿には超過理由書が必要となる。Microsoft Word本体の改ページ一致とMicrosoft Excel本体の描画は未確認である。
