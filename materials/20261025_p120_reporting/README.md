# P120開始と終了後集計の準備

P120の固定８条件の実行を開始した. [開始記録](../../reports/P120_execution_start_20261025.json)に同じ実装headの両workflowと両job成功、初回８入力と要約用４入力のnative計数、固定点の指紋を残した. この事前確認は12入力の計数だけで、生成、実API、評価は０. 中間成否を比較材料には使っていない.

終了後は全８条件を図示する. 必須欄を指定する指示、schema、要約本文の出力も実行役の費用に含め、別呼出し要約の費用も残す. 既知小計と使用量不明を区別し、未実行の枠も表示する. 私有領域の仮データで表示を確認したが、実結果の図は全閉鎖後に別途目視する. 各条件に実際の履歴置換の有無を表示し、要求回数と置換回数も区別する. 必須欄の指定は、制御が働いた証拠として扱わない.

全４対の費用を、実行役の増減と別呼出し要約の費用に分けて照合する. 専用要約を省いても、行動側の入力や再調査が増えれば総費用は減らない. 直後の入力短縮も全仕事の節約とは分ける. 最初の介入より前の完全要求SHAを両方式で比較し、以後の差を１つの原因に帰属させない.

既存の費用分解と介入前比較のテストを再利用し、全1,974テストと構文検査が成功. 表示のためだけに同じ検査を複製していない. P120の実行器、固定条件、予算は変更していない. この集計による追加モデル、API、tokenizer、評価は０. 原稿と未見12課題は保留し、新規性や一般的品質維持は主張しない.
