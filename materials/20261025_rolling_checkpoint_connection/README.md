# 再要約の実行接続と比較準備

再要約の制御部を共有予算付き推論、実課題worker、保存記録の監査へ接続した. この資料は実装と合成検査の記録であり、モデル実験の成果ではない. P122は専用の固定実行木で継続中で、その途中の成否や費用は読んでいない.

単発の別呼出し要約、最大３回の別呼出し要約、最大３回の同時要約を比較する準備ができた. 最初の２方式を対照に含め、既に成功していた課題の損失を安い費用で相殺しない. 現時点ではP120の4/4対3/4成功という全体の未達判定が最新の閉じた判断である.

追加26件を含む全2,037テストと構文検査が成功した. 初回の既存方式との要求一致、３回の更新でも予算を共有すること、不正要約の費用と待機、２回目の使用量不明で停止すること、未送信要約を課金要求と混同しないこと、コードとmetadataの結び付けを検査した. 監査は保存要求と原応答から再構成し、２回目の要約範囲や費用、native入力との結び付け、実行metadataの改変を検出する. 要約の意味保存は証明していない.

次のP123候補は既知４課題×３方式の12条件. １条件80呼出し、450,000入力＋出力token、1,800作業秒で、要約も同じ枠に含める. 実機での事前計数と生成は未実施. P122の全件閉鎖と確認後に、終了記録を結び付けた有限計画と同一headのCIを確定して開始する. P123の実行用configはまだ作成していないため、この準備だけで実行されることはない.
