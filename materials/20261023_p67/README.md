P25では全要求を支持した後に１生成・41,702 tokenが続いていた。これは実測節約額ではなく、次の有限比較の対象となる後続費用である。追加生成・API・評価・DB内容・保留群の読取は０。点検0.004410秒、元の公式成否は変更していない。

同じ既知１課題の３記録で、独立３課題ではない。件数を埋め込まず、終端ページ・公開メタデータ・CSV内容・バックアップ後の退会という順序を照合した。手書きの既知要求と信頼する公開APIの意味に依存し、新しい一般解釈器ではない。

使用量の確定フラグがない旧記録で最初の点検が停止したため、元のtoken値と旧監査に整合する分類処理を加えた。欠測値は補完していない。12反例検査と２互換処理検査に合格し、同じ３記録を保持した。
