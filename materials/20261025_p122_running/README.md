## 反復で調べること

同じ４課題、同じ２方式、同じ予算を保ち、seed基数57、157、257で３対ずつ比較する. 中央の反復では方式順を反転する. 元のP120を主集計に加えず、今回の全24枠が終了し所有serverが閉じてから、各対の成否、要約採用、全モデル要求のinput＋outputを読む.

全３対の費用が既知の課題だけ、差の平均、中央値、範囲、標本標準偏差を示す. 失敗で短く終了した結果を品質維持の節約とせず、要約未起動と未知使用量も残す. 写真の再現には全３対で両側成功、同時要約の採用、費用減少を要求する. 全体の採用には各反復で成功損失がないことなど、固定計画の追加条件も必要である.

これは既知４課題の少数の固定設定による確認で、未見課題への一般化や統計的非劣性を確立する試験ではない. ３対で値が揃っても別の写真課題への一般化は未確認のままである. 終了時に自動で全件監査と集計資料を作り、原稿はまとまった結果を確認後に別版へ反映する.
