# 参照統一の局所入力と終了済みの仕事を対応付ける

2026-10-24、終了済み資料の事後照合。P84の途中応答は読まず、追加生成・入力計数・環境実行・評価を行っていない。**P83で参照を統一した入力はP82のCSV実行にも実際に使われていたが、その２条件は両方未達だった。** 入力整合を課題成功へ読み替えないための確認である。

時間を非表示にしたHだけを対象とし、P80/P81の３反復×既知４課題とP82の２反復×同４課題、計20条件を全て照合した。課題ごとに旧３×新２の６対、全24対を残した。対は実行を共有しており、独立課題は４つだけである。時期の異なる群の事後比較であり、同時に割り付けた正規化の有無の実験ではない。

ここで比較したのはP83の保存要求である。進行中のP84は全条件で `cache_prompt=False` に変更した冷たい入力比較なので、P82のwarm状態や次応答を再現したと扱わない。今回もモデル用のtoken列、GPU状態、cache内部状態、全仕事への因果効果を新たに検証したわけではない。

P82のH内では成功３課題の反復間全列と書出しの既知部分が一致していたという[元の全件診断](../../docs/P82_findings.md)と、この群間照合は別の集計である。同じ記録を再利用した結果であり、新しい成功例や独立した追加試験に数えない。参照統一は不正な引数を修復せず、コードを完成させる処理でもない。今回の未達をIDだけで説明することもできない。
