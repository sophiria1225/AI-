# P123: 再要約を含む３方式の仕事全体比較

既知４課題×３方式の全12枠を残す. 単発の別呼出し要約、最大３回の別呼出し要約、最大３回の同時要約を比較する. 各枠は同じ80呼出し、450000入力＋出力トークン、1800作業秒の上限を共有し、追加要約、失敗、制御、後続処理をすべて計上する. 未知使用量を０や上限で補完せず、未実行と未評価も残す.

同時要約は２種類の対照それぞれで成功していた課題を落とさず、４課題合計と３方式すべてで成功した課題の合計で、双方より低い総トークンが必要である. 両方の反復方式で２回以上の採用を実際に確認する. この基準は既知課題の開発判断であり、一般的な品質維持、意味保存、非劣性や新規性を証明しない. 要約の時点、指示、schema、出力配分、後続行動も変わり得る.
