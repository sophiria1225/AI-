# 状態変更をまたぐ遅延復元の試作

取得時点の参照を保ったまま、確認できる整数項目の変更だけを記録し、必要になった時点で現在値から旧値を復元する実行器を追加した。参照が消えれば完全取得を回避する。未知の操作や履歴上限では従来の変更前取得に戻す。

通常の完全応答キャッシュは比較する両方式で共有した。現時点の値と復元した旧値は混ぜない。追加18検査と全256操作列を含む全1,394検査が成功した。誤った作用契約で旧値が誤り、検出できない反例も保持した。実サービス・モデル・課題評価は未実施で、実課題の改善や新規性は未確立。

この機構だけではP90の事前情報不在を解決しない。変更履歴からの復元や遅延した情報維持には既存研究があり、それだけで提案手法の独自性とはしない。作用の契約を自動検証する実装もまだない。
