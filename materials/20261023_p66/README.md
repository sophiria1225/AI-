# 通常の逐次終了制御 — 実行準備

P64/P65で見えた写真の完了後の処理を、公開記録に基づく通常の制御で実際に省けるか確かめる。全プログラムの実行後に根拠を検査し、支持がそろった時だけ完了通知。不明なら通常継続する。

既知の写真１課題×通常２条件、各１回。各80生成・45万token・30分・160 API。全体160生成・90万token・320 API・２評価の上限。条件・停止・採否は[固定計画](../../docs/experiments/P66_ordinary_completion.md)と[設定](../../configs/P66_ordinary_completion_v01.json)に保存する。

手書きの既知文型検査を新規性とはしない。元の通常実行との前半一致を仮定せず、終了後に照合する。P65の後続約3.9万tokenは、実行して品質・費用を評価するまで節約額と呼ばない。保留群０。
