# P78: API失敗通知の比較（実行中）

研究目的は、必要な情報と処理、最終品質を維持しながら、失敗と再取得を含む仕事全体の費用を減らすことである。

固定版5971a0d・PR #317の両CIを確認して８条件の実行を開始した。８初期入力の対応と収容可能性は全件確認済み。全条件の結果が閉じるまで成否や費用改善の判断は行わない。新規手法の実証とは位置づけない。

| 項目 | 固定内容 |
|---|---|
| 対象 | 既知４課題、各２条件を１回 |
| 比較 | 同じ実API例外を文字列で返す / Python例外として通知 |
| 共通 | 型付き正常値、持続Python、公開API名、最初からの推論履歴保持 |
| １条件 | 80モデル呼出し、450000論理token、1800秒、API写真160・他80 |
| 総枠 | ８条件、640モデル呼出し、3600000論理token、有限６時間サーバー |
| 欠測 | 使用量不明は不明のまま保存し、正確な合計費用差や採用判定を出さない |
| 品質 | 固定後の保存環境を１回ずつ独立評価、評価情報はモデルへ渡さない |
| 保留群 | 12課題は未開封を維持 |
