# 予算通知と停止規則の検証・10月22日午後の区切り

[PDF・12枚](AI_harness_budget_20261022.pdf)／[HTMLスライド](index.html)／[図表と全８条件CSV](figures/)／[結果・採らない理由](../../docs/P40_findings.md)。

題名は「AIハーネスの実行予算制御と総費用評価」。表紙は題名のみ。品質を保って不要な処理を減らす目的、上限管理とAIへの残量通知の違い、構成図、同じ途中状態から比較する理由、全条件の終了状況、課題ごとの成否と費用、停止規則、現在の新規性と限界を順に説明する。

６条件を最終評価、１条件は生成中の時間上限と使用量不明で終了、１条件は事前規則により未実行。４課題の比較は未完遂であり、欠測を失敗や費用０へ補完していない。予算通知は既存の基準方式で、独自方式の新規性・一般的な品質維持と費用削減は未確立。

PDF全12ページの描画とレイアウト検査を確認した。入力資料・生成器・確認したPDFのハッシュは`build_manifest.json`。HTMLは矢印キーで移動、Nで説明メモ、Oで一覧表示。進捗報告用であり、投稿用４ページ原稿ではない。

再生成：`python scripts/build_budget_report.py --terminated --pdf`。matplotlibとChromeが必要。通常モードは全８件完了を要求し、終了監査を使うモードを明示的に指定する。元のP38以前の資料は履歴として残す。
