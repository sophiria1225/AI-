# P88の全件結果を別稿へ反映する準備

P88の成否と出力を確認する前に、[日曜へ向けた主張判断](../../docs/weekend_decision_20261024.md)と[別稿生成処理](../../scripts/build_whole_task_reasoning_budget_draft.py)を用意した。通常の推論予算、入力正規化、予算を扱う学習方式との差を整理したが、新規手法の成立は主張しない。[原典の追加読取範囲](../../reports/weekend_claim_boundary_sources_20261024.json)。

監査済みの全８条件、全４対の成功喪失、成功・未達・成否不一致の費用、cacheと出力・実時間を別稿へ反映する。改善条件が成立、既知だが条件未達、欠測・未評価が残る場合で要旨と結論を分ける。実結果の監査が存在しなければ稿を作れず、既存稿を上書きしない。題名は合意済みの日英題名を保持し、著者情報は未設定とする。

追加４検査を含む全1,296件が3.194秒で通過した。合成データの組版は本文３頁＋英文１頁、文献７件を引用順に配置し、全４頁を目視確認した。和文87字・英文37語は欠測を想定した配置検査用の例であり、実結果の要旨ではない。教授用456字あらましは変更していない。

初回の書誌文字列のPython構文エラーと、最初の合成PDFのURLはみ出し１か所を記録した。文字列と書誌の組版を修正し、元の失敗出力を残した別版で確認した。引用順も確認している。[準備と失敗保存の記録](../../reports/P88_manuscript_preparation_20261024.json)。合成PDFと数値は私有保存し、実結果へ使用しない。

実際の生成先は `papers/202610_letter/reasoning_budget_control` を予定するが、現時点で作成していない。全条件終了、所有推論器停止、監査・資源集計の一致後にだけ生成する。実際の本文とPDFは別途全頁を確認する。通常設定の局所的な改善を新規性や一般的品質維持へ読み替えず、採録に足る中心知見かは全件結果と近接研究から判断する。
