# P111: 推論表示３方式の全仕事比較の準備

同じ既知４課題で、全保持、直近保持、P110の実行記録選別を最初から各１回比較する. [予定全12条件](planned_cells.csv)を固定し、失敗や不明を含めて全件を残す. まだ実モデル生成は開始していない.

15追加検査を含む全1,793検査成功. 実行器を通る合成fixtureで、正常実行後の省略、失敗後の原文再表示、未知使用量の停止、初回cache、同一要求の計数と生成、全記録の監査、安い失敗だけを採らない条件を確認した. 外部モデル、実API、生成Pythonはこの検査で使っていない.

各80生成・450,000論理token・1,800仕事秒、写真160 API・その他80 API. 両CIとjob成功後に所有サーバーを起動し、初期12入力を確認してから進める. 実行記録の選別規則は変更しない. 指紋、全費用、品質、実測cache、失敗、未実行を保存する. 原稿保留と未見12課題の分離を維持する.
