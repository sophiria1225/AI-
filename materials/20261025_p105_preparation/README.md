P102全36枠の実行と監査、P104全24入力の計数は終了済み. 今回の期待API数13/16/12は公開実装と模型から固定した期待値で、まだ実環境の結果ではない. 元の遅延版との差４回を、強い通常方式との差４回と解釈しない. 模型の５検査が成功し、全1,690検査も成功した. 最初の全体検査は新worktreeに既存vendor参照がなく４import errorとなり、その記録を残して固定済み依存先への参照を復元した. 依存先のコードは変更していない.
