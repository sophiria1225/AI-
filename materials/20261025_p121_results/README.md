各保存要求について、実際の入力と、実際に置換された古い履歴だけを戻した入力を数えた. 要約が未採用なら両入力は同一. 同時出力のmetadata非再入力、必須欄の指示とschema、実際の残予算通知、出力上限、seedなどは両入力で維持する. 別要約の要求と費用も保持する.

Dは後続の全保存要求における入力差の合計. Cは別呼出し要約の実測入力と出力の合計. D − Cは同じ行動列と実際の予算通知を固定した費用回収の算術であり、別要約をしなかった場合の実行結果や総節約の実績ではない. 同時出力の要約本文だけの生成tokenは分離計測していないため、独自のCを推定しない.

元の使用量不明は、入力の計数ができても不明のまま残す. 既知小計へDを足した仮想値が仕事予算を超える場合や、復元した入力と実際の出力予約がcontextを超える場合を明示する. 予算内でも別方式の行動や成功を保証しない. 成功例だけを選ばず、全失敗、欠測、未実行枠を含める.
