# P108 保存制御列の点検準備

P107の全２条件が終了してから、保存返答だけを使って当時のハーネス処理を一度照合する. 取得予約が、明示的な完全取得、状態変更前の取得、最後の参照の解放、別の完全応答による解除、未解消のままの停止のどれで終わったかを区別する.

[固定計画](../../docs/experiments/P108_read_view_lifetimes.md)／[設定とソース結合](../../configs/P108_read_view_lifetimes_v01.json)／[実装](../../scripts/replay_read_view_controls.py).

準備時点ではP107の途中成否や生成内容を読んでいない. 追加13検査と全1,730検査が成功した. 取得の取消しをAPI差やtoken差へ換算せず、必要なときの失敗と不明も保存する. 実記録の点検は未開始で、両CIとP107の全閉鎖を必須とする. モデル、環境API、評価、生成コードの再実行は０. 原稿は保留する.
