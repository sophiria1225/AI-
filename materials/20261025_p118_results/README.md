# P118: 一度だけの通常要約と全保持の比較

既知４課題×２方式の全８枠、全モデル要求、制御判断、役割別費用を含む. 要約役の入力・出力、失敗、不採用も共有する仕事予算へ計上する. 未知使用量は０や上限で補完せず、未実行・未評価も残す. 保存した推論、要約本文、課題データ、認証情報は公開しない.

これは通常対照の比較で、PAIRや初期台帳P14の再現、新提案の性能確認ではない. 要約は形式だけを検査し、元の意味の完全な保存を保証しない. 過去P111の採用基準未達と未知２件は変更しない. 原稿と未見12課題は保留する.
