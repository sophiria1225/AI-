# P112: 全仕事比較を読むための入力差診断を準備

P111の全件成否を読む前に、同じ実軌跡上で推論表示だけを変えた入力差を数えるコードと範囲を固定した. 現時点では診断の準備だけであり、新しい計数結果はない. P111の実行規則、予算、モデルは変更していない.

対象はP111の全12条件に保存された全生成試行で、各時点をfull、recent、execution_gatedの３表示で計数する. 最大2,880計数、全体900秒、生成・API・評価０. P111全件と所有サーバーが閉じて監査が終わってから、全記録の指紋を固定し、計画の両CI成功後に一度だけ数える.

入力の表示省略量と、実測の全仕事費用差を区別する. 同じ出力列を仮定して表示差を足し戻した値は、別方式の実測ではない. 会計上の残差を再試行や推論品質の因果効果とは呼ばない. 元の失敗、欠測、未実行を除外せず、不明使用量はnullのまま保つ.

合成記録による13件の検査と、全1,806件の検査が合格. 原文の復元、実要求との一致、例外後の再表示、未来の実行記録を使わないこと、不明使用量、未送信の停止表示、実際の方針に対する計数照合を確認した. 実taskの中間成績は見ていない.
