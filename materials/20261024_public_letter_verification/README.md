# 公開ファイルだけで原稿の出典と集計を確認する

研究リポジトリのルートで、Python 3.12の標準ライブラリだけを使って実行できる。モデル、Docker、AppWorld、TeX、非公開の実行履歴、外部接続は不要。

```sh
python3.12 -S scripts/verify_public_letter_evidence.py
```

JSONを新しいファイルへ残す場合は `--output /tmp/letter-evidence.json` を指定する。既存ファイルを上書きしない。異なるcheckoutで実行する場合は `--repo-root` を指定できる。対象は[中心を絞った検討稿](../../papers/202610_letter/execution_evidence_focus/README.md)。

## 今回確認できたこと

[実行結果](../../reports/public_letter_verification_20261024.json)では151ファイルの対応するhashを確認した。原稿PDFと組版記録・全頁目視記録の参照が同じPDFを指すこと、全24条件と全18実行診断がそろうことを確認し、公開された条件別レコードから集計し直した。

| 公開記録からの再計算 | 結果 |
|---|---:|
| P82の予定条件／モデル呼出し | 24／426 |
| P82の既知論理token／使用量不明生成 | 4,602,713／4 |
| P82の環境API送信 | 1,156 |
| P94の実行条件／保存文脈 | 18／1 |
| P94の先行再構成API／次操作API | 504／42 |
| P94の全プログラム実行 | 228 |

成功条件と未達条件を合わせて集計し、不明使用量がある全費用は `null` のままにする。全15入力間の比較を再計算し、ツールを提出しない出力の空列同士を有効な操作一致に数えない。３出力ずつの９対は依存する組合せであり、独立９課題へ読み替えない。構文差とAPI要求列の差も分ける。

## 確認の限界

このコマンドは公開されたファイルの整合性と算術を確かめる。非公開の要求・返答、保存プログラム、DB、評価器を再実行せず、実験そのものの追試は行わない。既存の目視記録を照合するだけでPDFを新たに目視・再組版するわけでもない。

公開記録とそのhashを一緒に書き換えた人がいないことを、hashだけで証明する仕組みではない。再現時は使用したGitの版を併記する。新規性・採録の十分性・一般的な品質維持は、このコマンドの成功からは結論しない。

検査では、未達費用の包含、不明・未実行の保持、重複条件、提出なし同士の比較、構文とAPI列の違い、表の数値変更、出典欠落、私有領域への参照を確認した。[実装](../../scripts/verify_public_letter_evidence.py)／[10検査](../../tests/test_public_letter_evidence.py)。
