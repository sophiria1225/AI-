# P99：ツール提出設定の通常対照を準備

P98全24実行・426生成の閉じた解析を根拠に、通常のauto/requiredを既知４課題の新しい８条件で比べる準備をした. 推論専用上限−1、残実時間非表示、返却推論、持続Python、型付きAPI、予算は共通にする. 初期要求の変更はtool_choiceだけで、サーバ処理による入力長の差も実測費用へ含める.

構造化提出がない21件、提出未完了４件、応答不明４件という観測から、形式改善が最終成果へ届くかを調べる. 通常設定であり、新手法とはしない. 形式の完成だけで通さず、全８件の評価と使用量、課題ごとの成功維持、失敗も含む総論理tokenの減少を要求する. CSVの達成は別に確認する.

追加14検査と全1,562検査成功. P97は固定比較を継続中で、途中の出力や成否はこの準備に用いていない. P97の終了記録と全件監査がそろうまで実行計画を作らず、新しいモデル/API/評価も開始しない. 準備headのCIだけで実験を起動せず、閉じたP97資料を固定した最終計画headの両CIとjobを必要とする.
