# P84の別途の初回開始判断

[判断理由と全条件](../../docs/P84_manual_execution_decision_20261024.md)、[機械可読な判断記録](../../reports/P84_manual_execution_decision_20261024.json)、[開始時点](../../reports/P84_execution_start_20261024.json)を保存した。元の自動停止・lockを残し、使用量不明４件やP82の不採用を変更していない。

[実際に一度実行した確認処理](decision_check.py)は、このMacの固定作業木と保存先を指定した記録用の写しである。モデルを起動する処理ではなく、一般利用向けの実行コマンドでもない。判断ファイルの既存確認、元の停止理由、別途の全件レビュー、24条件の全要求・応答hash、６保存入力、105依存、両CI、所有PID不在を照合し、別の判断ファイルを排他的に保存した。元ファイルと同一byteである。

P84の固定実行器は、その後に別の命令で初回起動した。初期６計数は一致し、生成を開始した。結果の採否・品質・全仕事費用改善を開始記録から先取りしない。
