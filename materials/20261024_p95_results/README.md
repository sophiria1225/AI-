返答が変わった21件はすべてloginだった。Spotify各９回、CSV Hのfile_system１回、返金のvenmo各１回である。これは返答全体の変化の観測であり、どのfieldだけが変わったか、認証状態を同一視できるか、ログインを省略できるかを示さない。返答が同じ９件はSpotifyアルバム詳細７件と写真のファイル詳細２件だった。

全150モデル境界のうち、送ったAPIが全て過去の同一要求だった境界は６件あったが、いずれも以前の成功が従来の読取範囲内に残る境界ではなかった。新しいローカル計算や推論の有無も点検していないため、不要な生成とは認定しない。API送信０の境界を全要求重複へ数えていない。
