# P99：通常の提出設定比較を原稿へつなぐ準備

全８条件の結果と全生成の提出状態を受け取る原稿生成処理を用意した. 全件の評価・使用量が既知で基準を満たす場合、満たさない場合、欠測や未評価が残る場合を分け、未実行を実行済みと書かない. CSVの最終成果、失敗を含む総費用、形式の指標を区別する.
