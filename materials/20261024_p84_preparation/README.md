# 参照ID差と次の出力の診断準備

P83で保存した全６入力×３反復、計18生成を準備する。まだモデルを起動・生成していない。P82の固定24条件比較を優先し、その終了と所有推論器の停止後に実行を判断する。

比較するのは、元の２入力、表示前に参照を統一した２入力、文章化されない参照IDの変更対照、内容変更対照。入力cacheは全件で無効にし、seed 70と出力上限4,096を揃える。全生成の予約は481,671論理token、上限500,000 token。生成したコードやAPI呼出しは実行しない。

[固定計画](../../docs/experiments/P84_fallback_output.md)／[先行研究との境界](../../docs/fallback_output_diagnostic_scope_20261024.md)。全18件、各条件内の一致、条件間の全15組、失敗・途中切れ・欠測を残す。分かるのは選んだ保存文脈での次の出力への局所効果までで、課題成功・全費用削減・新規手法の成立は測らない。
