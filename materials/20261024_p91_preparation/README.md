# P91 別取得元の部分情報と実際の対象プログラムの点検準備

アルバム・プレイリストから観測済みの曲IDと曲名を利用する別取得器を追加した。プレイリストで確認できるアーティスト順序と、すでに取得した名前も同じ状態版で照合する。未知項目を補わず、完全応答キャッシュと従来の無効化規則を保つ。[対応する公開契約](../../docs/joined_public_read_contract_20261024.md)。

固定点検はP88全８条件の既存32ファイル、全４曲詳細要求、120秒以内。各ファイル16 MiB、各条件4,000イベント・80生成、対象プログラム最大４出現、各20,000文字・5,000 ASTノード。元の全成否、150生成、既知1,689,160論理tokenと不明１、399 API、20例外を保持する。

対象要求の直前に利用できた項目と元のP89分類を併記する。その要求を含む実際のプログラムの構文も確認するが、構文箇所を実行回数・項目需要・参照寿命・取得回避へ換算しない。生の返答、引数、生成コードや認証情報は公開しない。
