# P122: 費用差のばらつきと成功損失の反復確認

P120の写真では別呼出し要約と同じく成功し、総tokenが7.50%減った. 一方、全４課題では4/4対3/4成功となり、CSVの成功を失った. この二つを同時に確認するため、同じ既知４課題×２方式×固定３設定の全24実行を準備した. これは準備資料であり、新しい実験結果ではない.

model seed基数57、157、257を固定し、中央の反復では方式順を逆にする. world seed42、要約方式、指示、起動閾値、出力枠と１課題の予算を維持する. 前回と同じseedでの再現１組と、別seed２組を含む. 過去のP120を新しい主集計へ混ぜず、成功課題だけを選ばない.

全３対の費用が既知の場合に、課題ごとの平均、中央値、最小、最大、標本標準偏差を報告する. 成否、要約の要求と採用、未知使用量を併記し、失敗で安く終わった分を同じ成果の節約へ換算しない. 三つの固定設定だけで統計的有意差、非劣性、別の課題への一般化を確立したとはしない.

各条件は全役を合わせて80モデル要求、450,000 token、1,800仕事秒. 全24条件の予約上限は1,920要求、10,800,000 token、2,400 API、24評価、server64,800秒. 実績費用とは別であり、終了時にはserverを閉じる. 全件を閉じるまで途中の成否を使った設定変更をしない.
