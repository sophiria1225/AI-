必要情報と最終品質を保つ効率化には，取得から終了までの費用評価が必要である．
\textbf{状態を保持したまま情報提示や実行制御を変えると，全仕事費用と成否はどう変わり，その差をどこまで介入に帰属できるか}を調べる．

\section{費用の定義}
仕事全体の論理トークンを
\begin{equation}
 T_{\rm work}=T_{\rm prefix}+\sum_{j=1}^{n}(I_j+O_j)
\end{equation}
とする．共通前半の実測値を各条件へ一度加え，開始時からの比較では前半を０とする．キャッシュ入力も$I_j$へ含める．
継続だけの値も示し，初回短縮量を全体の節約量へ，論理tokenを請求額・計算量・時間へ換算しない．
API，時間，実験用復元，評価，推論器のロード・常駐は別記し，重なる時間を足さない．
評価器単独の時間は表示比較では未計測で，稼働時間の残差からは求めない．

\section{解釈と結論}
同じ既知４課題・単一モデル・各条件１回の開発比較で，18診断も既知３課題９状態への事後介入である．
seedと初回cacheの一致は後続経路の再現保証ではない．返金D/Bも残時間通知等が異なり，差を一覧の効果にしない．
Bにも過去コード等のAPI名が残る（写真8/26名，精算10/26名）．省略対象は出自の確かな古い説明で，情報の完全消去は測っていない．

表示省略・推論保持・失敗通知の全体採用条件は未達だった．
通常終了制御の局所改善も一般化せず，全仕事費用，実作業，介入の発生，終了手続きを分けて評価する必要がある．
