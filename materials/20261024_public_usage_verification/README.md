# P100の公開記録を使う検算

リポジトリのルートで Python 3.12 以降を使い、次を実行する. 外部パッケージ、私有履歴、モデル、環境API、通信は不要.

```sh
python3.12 -S scripts/verify_public_usage_intervals.py
```

全12条件、223試行、不明２試行、全12課題対、全３方式対を保持して検算する. 16件の公開ファイルのhash、元のP97との要求識別子と会計の対応、入力計数と要求出力上限、条件ごとの区間、成功と未達の別集計、JSONとCSVの一致を確認する. 元の区間計算モジュールは呼ばず、公開された値から計算し直す.

確認された条件付き差は、F−Nが63,304〜103,360 token、F−Gが32,397〜74,997 token、G−Nが−11,693〜70,963 token. 成功した３課題の合計は各方式448,825 tokenで差０. 区間の差は全方式で未達となったCSV課題に由来する. 上限は記録された計数と生成上限が守られたという仮定を必要とする.

この検算は公開記録どうしの整合性を確認する. 私有の使用量原票、欠測２生成でのサーバ上限遵守、評価器の正しさ、CIの現在の状態は独立に確認しない. 欠測値を復元せず、下限０を実使用量として代入しない. 元の不採用判定、新手法未確立という判断も維持する. P100の分析を再実行した結果ではない.
