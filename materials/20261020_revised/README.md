# 研究アプローチを明確にした改訂資料

[PDF（16枚）](AI_harness_research_20261020.pdf) / [編集できるPowerPoint](AI_harness_research_20261020.pptx) / [本文](transcript.md)

研究の核心は「共有・共同方針で十分か、関連する判断と実行を一担当へ移す追加価値があるか」を切り分け、品質条件と全費用を踏まえて構成を選ぶこと。現在は新規性の候補を検証できる仕様へ具体化した段階で、担当変更の有効性は未実証。

旧資料が基盤の反復観察に偏っていたという指摘を受け、問い・既存研究・貢献・提案機構を前半へ移した。旧[29枚の進捗資料](../20261020/)はP4終了時点の記録として保持する。

| ページ | 内容 |
|---|---|
| 1–2 | 研究の問いと背景の具体例 |
| 3–4 | 動的再編・担当統合・介入価値の先行研究との重なり |
| 5–6 | 狙う貢献と提案機構の構成図 |
| 7–9 | 四条件、中央調整との対照、品質・費用の成功条件 |
| 10–11 | P3/P5の実測と、その結果では示せないこと |
| 12–14 | 今回の実装、次の検証、成果と反証条件 |
| 15–16 | 原典リンクと確認範囲 |

図表の値は[CSV](observations.csv)と[出典・ハッシュ](data_sources.json)から追跡できる。P3/P5は別の課題・予算で、各課題・方式1試行。成績を合算せず、小さな費用差を削減率としない。

再生成は資料用のPython環境で `python scripts/build_contribution_presentation.py`。必要パッケージは既存の[資料用依存版](../20261020/requirements-build.lock.txt)。フォントの実ファイルは再配布していない。本文、表、構成図はPPTX上で編集でき、実測グラフは画像とCSV・生成コードを保持する。

全16ページのPDF表示、文字、図表の数値、出典ハッシュ、リンク、文字の重なりを確認した。構成図と比較図・実測グラフは拡大表示でも確認した。[検査記録](review.json)。ネイティブPowerPointでの描画は未確認なので、PDFを基準表示にする。
