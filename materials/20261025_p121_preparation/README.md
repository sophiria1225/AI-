# P121: 要約後の入力差を調べる準備

P120の中間成否を読まず、P118、P119、P120の全24枠を対象とする診断を準備した. ３実験の全枠と所有serverが閉じてから、保存要求の入力を実際の表示と古い履歴の復元表示で一度ずつ数える. 最大3,840入力、全体900秒. モデル生成、保存Pythonの実行、API、評価は０.

実際に置換した履歴だけを戻し、同時出力のmetadata非再入力や追加指示、schema、予算通知、生成条件は両入力に残す. 要約が未採用の入力と、別呼出し要約の要求は両側で同じとする. 各後続入力での差を合計し、別要約の実測費用と照合する. 同時出力の要約本文だけの出力tokenは推定しない.

未知の使用量を入力計数で埋めず、全失敗、欠測、未実行枠を保持する. 仮想復元のcontext超過や仕事token予算超過を示す. 同じ行動を続けた場合の入力差の診断であり、要約をしなかった別実行の成功や総節約を主張しない.

新規９件を含む全1,983テストと構文検査が成功. P120実行と全閉鎖後の集計は、それぞれ既存の固定木と起動済み処理が継続する. この準備では元の実験を変更せず、実記録の束縛、語彙計数とも未開始. 原稿と未見12課題は保留する.
