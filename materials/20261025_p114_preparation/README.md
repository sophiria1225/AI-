# P114: 通常の内部推論非再入力対照の準備

公開コードと観測、Python状態、完全保存履歴を保持し、直前や失敗時を含む全過去推論欄を送信時だけ省く. 推論の生成予算は−1、出力枠4,096のまま. 生成した推論を費用から除かない. 追加の選別LLMは使わない.
