# P96準備：認証の由来を使う再観測と２つの通常対照

P95全８条件の観測を受け、同じ399要求・150モデル境界を、全引数一致、認証引数の単純除外、過去の成功した同一login要求の由来群で比較する。値の再観測と、その時点の権限・状態・進捗を混同しない。モデルへ通知する候補は、対象読取が全て以前のモデル境界で得た値の再観測で、その他は同じloginの再成功だけという状態が２回連続した境界に固定する。
