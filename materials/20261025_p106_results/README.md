# P106: 通常キャッシュを揃えるとAPI数は12対12

同じ手書き７段階を即時版と参照共有版で実行し、全14段階が正常終了した. APIは両側12、７段階の標準出力は両側およびP105とすべて一致した. 111私有記録の照合も成功した. [判断と費用](../../docs/P106_findings.md).
