# 推論ブロック予算の固定backend検査

進行中のP88へ接続せず、同じ固定版 `llama.cpp 620d2225cc436ab0b001e3200e590e3b286ef9ab` の共有ライブラリを合成入力で検査した。モデル・語彙の読込、token化、ニューラルネットの推論、環境API、課題評価は０。モデルが実際に何を出力したかは調べていない。[検査と初回失敗の記録](../../reports/native_reasoning_budget_check_20261024.json)。

上流の[既存検査](https://github.com/ggml-org/llama.cpp/blob/620d2225cc436ab0b001e3200e590e3b286ef9ab/tests/test-reasoning-budget.cpp)は12のsamplerケースとUTF-8判定関数を通過した。これとは別に、[４ケースの合成probe](../../scripts/probe_native_reasoning_budget.cpp)で実際の専用値2,048を使い、同じnative samplerの状態遷移を確認した。

| 合成ケース | 与えたtoken数 | 強制した終了token数 | 最後の状態 |
|---|---:|---:|---|
| ８token後に自然終了 | 9 | 0 | 終了 |
| 2,048token後に終了を強制 | 2,049 | 1 | 終了 |
| 終了後に新ブロックを開始し、通算4,096で入力を止める | 4,096 | 1 | 計数中 |
| 専用値は2,048のまま、通算1,024で入力を止める | 1,024 | 0 | 計数中 |

通算4,096のケースは推論用の合成内容4,094、終了タグ１、再開タグ１である。専用上限はブロックごとに再設定されるため、全出力の半分を操作へ必ず残す保証ではないという既存の説明と一致する。全出力上限はprobeの入力ループで模擬しており、HTTP経路やサーバーの全出力停止機能を動的に検証したものではない。

合成IDと手書きの候補値を使い、実語彙を持つsamplerのUTF-8待機経路は検査していない。UTF-8判定関数の上流検査を、その統合検査と混同しない。P88で再開が実際に起きたか、操作が完成したか、品質や全費用が改善したかは全件終了後の別判断である。新しい制御手法や反例の発生率の主張ではない。

初回は上流検査を通過した後、probeのJSON型が固定版の公開インターフェースと異なりコンパイルで停止した。ローカルの型別名を `common_json` に直し、元の失敗記録を保持して別の出力先で処理全体を確認した。上流検査の２回の成功を24の独立ケースとは数えない。修正版のコンパイル・実行段階は計1.240850秒、初回の記録範囲は1.586224秒だった。上流ソースと共有ライブラリは変更していない。

[実出力JSON](native_results.json)は私有の修正版終了記録とbyte一致する。`source_sha256` は固定した外部ソース内の相対パス、`repo_source_sha256` はこのリポジトリ内の相対パスである。[再現処理](../../scripts/check_native_reasoning_budget.py)は固定ヘッダ・共有ライブラリ・ソースhashを検証し、新しい出力先だけを受け付ける。P88の計画・値・実行を変更していない。
