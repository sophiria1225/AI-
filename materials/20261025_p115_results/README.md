全保存要求をfull、recent、execution_gated、public_onlyで再構成した. 元の実行はP114のpublic_onlyだけであり、仮想表示に成否を付与しない. Dは保存された同じ応答列と実際の残予算通知を固定した局所的入力差である.

`C_public - C_historical_full = -D + (C_public + D - C_historical_full)`と整理する. fullの実測参照は過去のP111で、同時実行の対照ではない. 残差を行動変化や推論品質など特定原因の因果効果とは呼ばない. 不明使用量があれば実測差と残差をnullに保つ. 計数できても不明な実使用量は確定しない.

仮想入力に4,096出力予約を加えた値が65,536 contextに収まるかを各行に記録する. 収まっても仕事全体のtoken予算で送信できた保証はない. 隣接仮想入力の共通prefixは実測cache使用量ではない. 全失敗、欠測、未実行を残す.
