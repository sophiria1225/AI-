# P118: 一度だけの通常要約を同じ仕事費用で比べる準備

既知４課題で全保持と１回要約を各１回、計８条件で比べる. 16,384 native token以上かつ完了３ターン以上になった最初の機会だけを対象にし、原指示と直近２ターンを残す. 要約の形式不備、不採用、失敗も実行役と同じ費用に含める. 使用量不明なら継続しない. 新提案やPAIRの再現ではない.

新規21テストを含む全1,880テストと構文検査通過. 最初の実行器接続テストでは、旧集計が実行役だけを想定していたため要約役の２検査が不一致で停止した. そのログを残し、共有する送信記録から両役と応答欠測を数える処理を追加してから合格した. 実モデル、生成Python、実APIをテストで動かしていない.

各条件80呼出し・450,000 token・1,800仕事秒で、要約はその内数. 所有server21,600秒. 同一headの両workflow・両job成功後に初回８入力と要約経路１入力を計数し、固定順で一度だけ実行する. 現在は未開始. P111の採用基準未達と未知２件、原稿保留、未見12課題の分離を維持する.
