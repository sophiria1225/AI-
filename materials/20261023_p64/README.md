正確な公開名で呼べる機能は通常基準の整備。新手法や一般的な品質維持の実証ではない。既知課題の各１回、能力説明も変わる比較として報告する。保留群の閲覧０。旧P55/P56の原稿の知見は当時の接続条件の下の局所診断として保持する。
